## 1. 核心纪律：当日可知（无未来函数）

**定义**（调研线口径）：T 日收盘后生成信号，只允许使用 T 日及之前的数据；成交发生在 T+1 开盘。

| 环节 | 纪律 | 违反后果 |
|---|---|---|
| 信号生成 | T 日收盘数据算信号 | 用 T 日盘中/未来数据 = 自欺 |
| 成交 | T+1 开盘价（跳空按实际开盘价） | 按信号价成交 = 高估收益 |
| 止损触发 | T+N 日开盘已跌破则按开盘价成交（悲观口径） | 按止损价成交 = 低估亏损 |
| 指标 | MA/RSI/KDJ/筹码全部由日K自算，截至 T 日 | 用 T+1 发布的指标 = 未来函数 |
| 基本面 | PR 为 point-in-time：中报发布前用 FY2025 年报，8 月底发布后切换滚动 TTM（FY25+H1_26−H1_25） | 用当期已发布财报反推历史 = 未来函数 |

**双轨差异说明（如实记录）**：产品实现线为**盘中实时扫描**（9:30-11:30 / 13:00-15:00，5 分钟轮询 + WebSocket 推送），信号在盘中产生并即时推送；调研方法论线的验证口径为日级批处理（收盘后计算、T+1 开盘成交）。两条口径的差异是设计取向不同（产品重实时发现、调研重可验证统计），**回测结论（06）只对调研口径成立，不可直接外推为产品盘中信号的收益承诺**。

**踩坑记录**：tech 指标按动作日逐个拉取导致 899 天中仅 112 天覆盖，RSI6 过滤误杀 51 个动量信号 → 改为日K自算。

## 2. 数据口径约束

| 约束 | 规定 | 原因 |
|---|---|---|
| 复权 | **不复权**（adjust_type=0 / fqt=0） | 与实盘下单价一致；复权价改写历史，MA/RSI/筹码全部偏移 |
| K线周期 | 日K（调研线 Phase 1）；产品线日K + 分钟K双路径（分钟路径仅非实时决策用，见 02） | 分钟K混入日K信号破坏"当日可知"纪律 |
| 价格字段 | o/h/l/c/prev/pct/amp/vol/amount/turn 全字段 | 换手率是筹码算法核心输入 |
| 指数 | 上证 000001.SH（R13 regime 判定） | 与验证口径一致 |
| 时区 | 东八区（Asia/Shanghai） | 跨日错位会使信号日与成交日整体偏移一天 |

## 3. 交易制度约束（A股）

| 约束 | 规定 |
|---|---|
| T+1 | 当日买入次日才能卖出（倒T规则 R06 的设计前提：必须有底仓才能"冲高卖"） |
| 涨跌停 | 一字板无法成交 → 信号可执行性检查（自动标注）；limit 按板块：主板 10%、ST 5%、双创（688/300）20%，代码板块判定用静态映射表 |

| 停牌 | 停牌日分布不变；到期收盘缺失时向后找第一个有收盘价日 |

## 4. 仓位约束（Kelly 体系，双轨并列）

### 4.1 调研线（rules v1.4，写入纪律）

```
f* = (bp − q) / b          # 凯利公式，p=胜率 q=1−p b=盈亏比
f_half = f* × 0.5          # 半凯利（防参数高估）
f_adj = f_half × √(N标的/N信号)   # 相关性折扣（同源信号不重复下注）
f_final = min(f_adj, 25%)  # 单规则仓位上限
负期望（f*≤0）→ 仓位 = 0    # 自动禁用
```

- 相关性折扣必须**分池计算**（主池/扩展池不可混算）
- 单位铁律：`position_pct` 全链路**百分数**（15.0=15%），入库前断言 `0 < position ≤ 25`

### 4.2 产品线（PositionSizer，代码实证）

八步计算：动态参数读取（SignalTracker ≥10 笔）→ 基础仓位（评分 90+→40% / 80-90→35% / 70-80→30% / 60-70→25% / 50-60→20% / <50→10%）→ 市场调整（BULL ×1.2 / BEAR ×0.2）→ 波动率调整 → Kelly（组合调整 1/√N）→ 总仓位限制 → 最终 5%-40% 夹紧。参数：半凯利 fraction 0.5、单只上限 40%、组合上限 80%、最小交易 10 笔、默认胜率 0.55、默认盈亏比 1.5。

> 两条线的上限不同（25% vs 40%/80%）：调研线是单规则统计口径，产品线是组合管理口径。生产以产品线为准；调研线的 25% 是其回测结论的边界条件。

## 5. 风控约束（双轨合并）

### 5.1 账户级（调研线）

| 规则 | 参数 | 说明 |
|---|---|---|
| R10 连亏保护 | 连亏 3 笔 或 回撤 −10% → 停止开新仓 | 最大单笔 −17.57% 教训 |
| 单笔止损 | 各规则 exit.stop_loss_pct（−4% ~ −7%，悲观开盘口径） | 日K收盘价判定，不用盘中价 |
| R13 变体 | 上证 bias20 ≤ −2% 时禁 R05 低吸 | 半年确认有效（被禁 35 笔均 −1.65%） |
| DR-01 属性日 | 不新开仓，持仓票减仓 | 属性日基准 −0.20%/笔（v1.4 幅度下调） |

### 5.2 产品线（代码实证）

| 模块 | 参数 |
|---|---|
| RiskManager | 止损 5%、最大回撤 10%、最大连亏 3 次、单票上限 25%、总仓位 100% |
| StopLossManager | 固定 8% / 追踪 5%（盈利 10% 激活）/ ATR 2 倍 / 波动率自适应；止盈 20% 或移动止盈（15% 激活回撤 3%）；取最严格止损 |
| CorrelationManager | 单板块 ≤30%、前三板块 ≤60%、高相关 >0.7 预警、分散度评分 0-100 |
| RiskBucket | 行业 >3 只/概念 >2 只扣分、CVaR 风格单策略回撤 2%、连亏 3 次熔断冻结 |
| CooldownManager | 4 小时冷却（`signal_cooldown:{code}:{date}`）、幂等 md5 hash 1h |
| 断路器层（PRD） | 一级熔断：回撤 >8% 冻结开仓至修复 <5%；二级预警：单日浮亏 >2% 仓位减半；常规：单票 >40% 或板块 >30% 拒绝 |

## 6. 信号质量约束（调研线准入门槛，详见 06）

- 规则入库门槛：**≥6 个月窗口验证**（3 个月结论有 5 项在半年翻转）
- 最小样本：单规则信号 **≥30 笔**才允许启用（不足则标"样本不足"）
- 月度稳定性：任何规则按月剖切不得出现"单月贡献全部盈利"
- 双池一致性：主池与扩展池方向必须一致（泛化性检验）
- 样本量分档：≥100 可进采纳配置 / 30-99 方向性参考（评级 ≤B）/ 10-29 仅记录 / <10 不给 Kelly 仓位
