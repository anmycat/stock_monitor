## 这是什么

一套运行在阿里云 ECS 上的**A 股量化信号系统（量化扫描系统 V5）**：多源行情接口 → 反信号过滤 + 门控模型 + 多策略引擎 + 八因子评分 + HMM 市场状态 + Kelly 仓位 → Web/WebSocket/钉钉等多渠道推送 → 人工执行。全部规则经过**双池回测 + 半年实盘验证 + 内容审计**三重检验。

**本文档集包含两条内容线**（详见 00 §0）：
- **产品实现线**：quant_engine v5.0.0 可运行代码 + PRD v3.0（符合度 100%）
- **调研方法论线**：rules v1.6（22 条规则，2026-10-21 用户确认落库）+ 半年实盘验证（614 笔信号/3151 基准样本）+ **3 个月两窗口复验（v1 288 笔 / v2 196 笔，见 14 §5/§5.9）**

**当前采纳配置**（v1.5→v1.6，2026-10-16 裁定 / 2026-10-21 D30 第二窗口验真再确认并落库）：默认过滤器 **R12（pre10>25% 弱过滤）+ R13 变体**（指数 bias20 ≤ −2% 禁 R05 低吸，两窗口复验再确认）；**R06 倒T 已移出买入信号池**（avoidance，两窗口稳定亏损，剔除后均盈亏 +0.34%→+0.88%）；Kelly v1.6 执行口径（**R02 0 / R01 2.46% / R04 2.84% / R05 0 / 混合 1.92%**——R02/R05 第二窗口转负无正期望置 0，2026-10-21 用户确认）；R02 涨停低开 3M-v2 转负（−0.12%），**"最强规则"声明已撤销**（v1 收益由 5 笔早期暴利单驱动，重叠窗口分毫不差；降级为"高方差尖兵"）；C01 保留选股层、交易叠加层撤回。

## 三条不可退让的底线

1. **当日可知纪律**：信号日 T 收盘后计算，T+1 开盘成交假设——回测与生产同一口径，杜绝未来函数
2. **先审计数据，再统计结论**：本研究两次被数据缺陷误导（neodata 省略标记、周末占位行）——每次全量验证前必跑数据完整性五项检查
3. **≥6 个月窗口 + n≥30 + 双池方向一致**：新规则准入门槛；不足样本只记录不采纳
