## 2. 信号生产流水线（双轨并列）

### 2.1 产品线（代码实证）

**单股路径**（StrategyDispatcher）：
```
AntiSignalFilter（高位>0.92/连涨8天/假突破/空头排列 过滤）
   → GateModel（趋势+资金+触发+分钟触发 四门控，任一不过即拒）
   → _run_builtin_strategies（按市场类型选 趋势/低吸，取最高分）
   → _apply_factor_scoring（策略分70% + 八因子分30% 融合）
   → 连亏/回撤检查 → position_factor 调整 → Signal（BUY/WATCH/SKIP）
```

**全市场路径**（ThreeLayerFunnel）：
```
L1 硬筛全市场 → L2 因子评分 + YAML 策略评分排序
   → L2.5 LLMRanker（可选，结构化 JSON 排序，失败透传因子排序）
   → L3 深度分析 Top N → CandidateContext 新闻增强
```

### 2.2 调研线（六层，见 00 §3.2）

数据层 → 因子层 → 资金层 → 射程层 → 过滤层 → 仓位层 → Signal 契约。

## 3. 射程矩阵：规则 × 资金属性（调研线，docs/09 实证）

信号日资金属性决定规则可用性：

| 规则 | 起爆日 HC-01 | 游资日 YZ-01 | 慢资金日 SC-01 | 无属性日 | 射程结论 |
|---|---|---|---|---|---|
| R01 动量突破 | −0.23% | — | — | −2.45% | 起爆日略优，样本不足待扩 |
| R02 涨停开板低吸 | **+4.59%** | −4.62% | — | +3.67% | **只在起爆日用** |
| R04 趋势回踩MA20 | — | +4.08% | −0.09% | +0.54% | 主池有效；扩展池价值股 −1.82% 失效 |
| R05 深度回调低吸 | — | — | **−4.00%（胜率0%）** | +0.20% | **慢资金票禁用** |
| R06 倒T | **−9.04%** | −2.77% | — | **+0.56%** | **v1.5 起整体 avoidance：不再作为买入信号**（两窗口稳定亏损，见 §4） |

> 口径：3 个月双池验证数据。半年窗口（v1.4）确认：R02 涨停低开仍为最强交易规则（+3.53%，n=44）；R01 在起爆日/游资日的射程矛盾样本仍不足（n=13/9），维持不改矩阵。

**射程原则（写入纪律）**：
1. 起爆属性日：只做 R01/R02（动量方向），禁止倒T
2. 游资属性日：只做 R04 回踩，禁止 R02 低吸、禁止倒T
3. 慢资金属性日：禁止 R05（无反弹），可中线布局但无做T空间
4. 无属性日：倒T的最佳射程——**但 v1.5 起 R06 整体降级为 avoidance（回避/减仓参考），此射程仅作反向信号使用**（出现倒T形态 = 不买入/减仓提示）

**半年新发现（待扩容确认，暂不改矩阵）**：R01 在 HC-01 起爆日仅 10 笔 −0.75%，在 YZ-01 游资日 7 笔 +3.16%——与"起爆日做动量最优"印象矛盾，样本量小，记录待验证。

**3M 复验新增观察项**（14 §5.7，样本不足不入 v1.5）：
- **YZ-01 游资日禁 R02**：3M n=13、胜率 30.8%、均盈亏 −2.10%（R02 全窗口 3M +1.90%）——同规则在不同资金属性日表现分裂；待 A5 扩容后复验
- **HC-01 起爆日基准异常强**：3M n=63、胜率 65.1%、均盈亏 +7.20%——环境判断本身很强但规则信号未能充分捕捉（R01/R02 在该属性日仅 +0.61%/+4.32%），列入 v1.5 观察位

## 6. 规则×规则叠加纪律（调研线）

1. **同票同日多规则触发**：取评级最高者（A>B>C），其余记入 events 供复盘（不静默丢弃）
2. **过滤前置于信号**：资金属性 → 射程矩阵 → R11/R13 过滤 → 才允许规则开仓
3. **持仓期每日重算**：DR-01 派发→减仓建议；**R06 倒T→回避/减仓提示（v1.5 起不再产生做T买入建议）**；R10 冻结→停开新仓
4. **无理由随手单禁令（R09）**：系统不出射程外/证伪规则/D 级信号——把"不交易"做成默认动作

## 7. 反向校准样本的特殊定位

博主实盘交易样本（82 条动作）经推导验证为**反向数据**：其最大亏损来自深跌低吸；筹码维度上其 43 笔买入全部命中 R11 回避/亏损带。系统不跟踪其观点，但该交易记录持续作为**反向校准样本**：每月统计其动作与信号引擎的背离度，背离扩大=市场可能反向（仅记录，不直接开仓）。

## 8. 池与规则的维护节奏

| 频率 | 动作 |
|---|---|
| 每交易日 | 数据拉取→因子→信号→推送（产品线：盘中 5 分钟轮询 + beat 120s 循环） |
| 每周末 | 周报：信号胜率/持仓盈亏/风控状态/射程外触发统计 |
| 每月 | 滚动重估各规则 n/胜率/盈亏比；Kelly 参数月度更新 |
| 每月 1 日 | **月度复验门禁（v1.5 新增）**：重跑 `validate_3m_recent.py`（窗口滚动），连续两月均盈亏 >0 且胜率不低于无过滤口径才恢复标准仓位，否则降仓位 |
| 每季 | 财报季更新 R11 基本面快照；评级表滚动更新 |
| 扩容时 | 新票过双池验证后才进生产池；≥6 个月窗口结论才准入规则库 |
