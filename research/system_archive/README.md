# 股票信号系统 · 方案文档集（system/）

> 版本：v1.0 · 2026-10-15 · 规则库 `methodology_rules.json` **v1.4**

## 这是什么

一套运行在阿里云上的**个人股票信号系统**：通过行情接口发现交易机会、按经过实盘验证的规则引擎判断、推送信号卡片到手机、由人工执行。全部规则来自对 60+ 个公开方法论源（博主/GitHub项目）的蒸馏，并经过**双池回测 + 半年实盘验证 + 内容审计**三重检验。

**当前采纳配置**（docs/14 v1.4，半年窗口 2026-04-13~10-13，614笔信号/3151基准样本）：
- 唯一默认过滤器：**R13 变体**（上证指数 bias20 ≤ −2% 时禁止 R05 低吸）——被禁35笔均−1.65%，启用后 +0.22%→+0.34%/笔
- R11 市赚率 = 选股层负面清单；R12 预期差 = 默认关闭；C01 = 最稳健筹码选股参考（+2.79%）
- Kelly 半凯利 + 25% 上限 + 相关性折扣；R02 涨停低开为半年最强交易规则（+3.53%）

## 与 docs/ 的关系

- `docs/` = **调研与验证的过程档案**（按时间/来源组织：博主蒸馏、项目蒸馏、各轮验证报告）
- `system/` = **按功能重组的方案文档**（本文档集，内容全部来自 docs/ 的去来源化整理）
- `rules/methodology_rules.json` = **唯一可执行配置源**（v1.4，22条规则 + Kelly参数 + 验证记录）
- 三者关系：docs/ 是证据链，system/ 是说明书，rules/ 是执行体

---

## 三条不可退让的底线

1. **当日可知纪律**：信号日 T 收盘后计算，T+1 开盘成交假设——回测与生产同一口径，杜绝未来函数
2. **先审计数据，再统计结论**：本研究两次被数据缺陷误导（neodata 省略标记、周末占位行）——每次全量验证前必跑 system/12 §2 五项检查
3. **≥6个月窗口 + n≥30 + 双池方向一致**：新规则准入门槛；不足样本只记录不采纳
