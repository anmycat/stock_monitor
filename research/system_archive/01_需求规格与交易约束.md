# 01 · 需求规格与交易约束

> 版本：v1.0（2026-10-15）｜本文件是全部规则与回测的**纪律层**，任何模块不得违反

---

## 1. 核心纪律：当日可知（无未来函数）

**定义**：T 日收盘后生成信号，只允许使用 T 日及之前的数据；成交发生在 T+1 开盘。

| 环节 | 纪律 | 违反后果 |
|---|---|---|
| 信号生成 | T 日收盘数据算信号 | 用T日盘中/未来数据=自欺 |
| 成交 | T+1 开盘价（若跳空按实际开盘价） | 按信号价成交=高估收益 |
| 止损触发 | T+N 日开盘已跌破则按开盘价成交（悲观口径） | 按止损价成交=低估亏损 |
| 指标 | MA/RSI/KDJ/筹码全部由日K自算，截至T日 | 用T+1发布的指标=未来函数 |
| 基本面 | PR 为 point-in-time：中报发布前用 FY2025 年报，8月底发布后切换滚动TTM（FY25+H1_26-H1_25） | 用当期已发布财报反推历史=未来函数 |

**踩坑记录**：tech 指标按动作日逐个拉取导致 899 天中仅 112 天覆盖，RSI6 过滤误杀 51 个动量信号 → 改为日K自算（docs/09 bug#1）。

## 2. 数据口径约束

| 约束 | 规定 | 原因 |
|---|---|---|
| 复权 | **不复权（adjust_type=0 / fqt=0）** | 与博主截图成交价比对的前提；复权价与实盘下单价不一致 |
| K线周期 | 日K（Phase 1） | 分钟级为 Phase 2 |
| 价格字段 | o/h/l/c/prev/pct/amp/vol/turn 全字段 | 换手率是筹码算法核心输入（537天缺失事故后已修复，见02） |
| 指数 | 上证 000001.SH（regime 判定） | 与 docs/11 验证口径一致 |

## 3. 交易制度约束（A股）

| 约束 | 规定 |
|---|---|
| T+1 | 当日买入次日才能卖出（倒T规则R06的设计前提：必须有底仓才能"冲高卖"） |
| 涨跌停 | 一字板无法成交 → 信号可执行性检查（07 模块自动标注） |
| 做空 | 不允许。R06 的"卖"是有底仓的做T，不是裸做空 |
| 停牌 | 停牌日分布不变；到期收盘缺失时向后找第一个有收盘价日（引擎已修复） |

## 4. 仓位约束（Kelly 体系）

```
f* = (bp - q) / b          # 凯利公式，p=胜率 q=1-p b=盈亏比
f_half = f* / 2            # 半凯利（防参数高估）
f_adj = f_half × √(N标的/N信号)   # 相关性折扣（同源信号不重复下注）
f_final = min(f_adj, 25%)  # 单规则仓位上限
负期望（f*≤0）→ 仓位 = 0    # 自动禁用（R05 实测触发）
```

- 实测（docs/14）：R05 胜率35.6%/盈亏比1.52 → f*=0 → **自动零仓，无需人工低吸禁令**
- 相关性折扣必须**分池计算**（主池/扩展池不可混算，docs/09 bug）

## 5. 风控约束

| 规则 | 参数 | 说明 |
|---|---|---|
| R10 连亏保护 | 连亏3笔 或 回撤-10% → 停止开新仓 | docs/07 最大单笔-17.57%教训 |

## 6. 信号质量约束（详见 08）

- 规则入库门槛：≥6个月窗口验证（3个月结论有5项在半年翻转，docs/14）
- 最小样本：单规则信号 ≥30 笔才允许启用（不足则标"样本不足"）
- 月度稳定性：任何规则按月剖切不得出现"单月贡献全部盈利"
- 双池一致性：主池与扩展池方向必须一致（泛化性检验）
