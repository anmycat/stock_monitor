## 1. 因子计算三原则

| 原则 | 内容 | 反例（本项目踩过的坑） |
|---|---|---|
| **自算，不取快照** | MA/RSI/KDJ/筹码分布全部由日K序列在引擎内计算 | neodata 估值快照 PE 陈旧错误（docs/11 §7）→ PE/ROE 改为 FY 财报 point-in-time 自算 |
| **当日可知** | T 日 15:00 收盘后，计算信号所需的全部数据已完整落库 | 技术指标按动作日逐个拉取导致 112/899 天稀疏（docs/09 bug）→ 日K全序列自算 |
| **不复权口径** | 一切计算基于不复权价格 | 复权会改写历史价，全部验证结论错位 |

## 2. 基础因子定义（全部由日K自算）

| 因子 | 定义 | 备注 |
|---|---|---|
| `ma5`/`ma20` | 5/20 日收盘均价 | 需 ≥20 日历史，故每次拉取 120 日 |
| `rsi6` | 6 日 RSI | 超买 ≥80 / 超卖 ≤35 |
| `kdj_j` | KDJ 的 J 值 | 极端值预警 |
| `bias_ma20` | (收盘 − MA20) / MA20 × 100% | R13 变体的核心输入（指数口径） |
| `vol_ratio` | 当日量 / 前 5 日均量 | 放量 ≥1.2 / 缩量 ≤0.8 |
| `streak` | 连涨天数（负=连跌） | docs/07 验证的盈亏分水岭：连涨 ≥2 |
| `pct_5d`/`pct_10d` | 近 5/10 日累计涨跌幅% | R12 透支度输入（pre10>25% 弱过滤） |
| `pos` | 收盘日内位置 (c−l)/(h−l) | ≤0.4=日内弱势（派发形态）；≥0.85=冲高（R06） |
| `new_high_20` | 是否创 20 日新高 | R01/HC-01 辅助确认 |
| `chip_*` | 筹码分布族（§3） | C01-C05 的全部输入 |

## 3. 筹码分布算法（C01-C05 的基石）

采用**通达信口径移动成本分布**：三角形分布 + 换手衰减递推。

```
D(t) = D(t-1) × (1 − 换手率) + 当日三角形成本分布
```

- 当日成本：在 [最低, 最高] 区间按均价（中价近似）为峰做三角形分布，面积 = 当日成交量
- 衰减递推：旧筹码按换手率遗忘（换手即换手，筹码转移）
- 网格：100 格，价格区间随行情扩展；**扩展时按密度守恒插值**（值/格宽），网格扩展按价格位置映射注入

### 3.1 派生指标

| 指标 | 定义 | 用途 |
|---|---|---|
| `profit_ratio` | 获利盘比例（成本 ≤ 收盘价的筹码占比） | C01/C03 核心 |
| `avg_cost` | 筹码平均成本 | 与现价比较 |
| `cost5`/`cost95` | 5%/95% 分位成本（90% 成本区间） | 集中度计算 |
| `concentration` | (cost95 − cost5) / 收盘价 × 100% | 单峰密集度 |
| `peak_price`/`peak_pos` | 主峰价格 / 主峰在 60 日区间的分位 | **第一判别变量** |
| `n_peaks` | 检出独立峰数量 | 多峰/单峰形态 |

### 3.2 算法正确性验证（两个独立证据）

1. **7 个合成场景**符合理论预期：横盘→单峰密集获利盘≈50%；一字板→获利盘≈90%；高位派发→峰上移获利盘≈98.6%；箱体→双峰可检出
2. **与东方财富筹码接口交叉验证**：博主 49 个交易日样本，获利盘平均绝对误差 **2.06pp**，90% 样本误差 ≤5pp

> 实现：`scripts/chip_distribution.py`。历史上修过 3 个 bug（递推系数、网格扩展面积、注入错位），教训记录在 docs/13——**筹码算法没有直观的正确性直觉，必须用合成场景+外部对账双线验证**。

## 4. 资金性质四分类（选股/排雷前置层）

资金分类**不直接产生交易信号**，先判资金属性、再匹配规则射程（射程矩阵见 05 §3）。

| 标签 | 判定条件 | 含义 | 半年实证（docs/14 V2） |
|---|---|---|---|
| **SC-01 慢资金潜伏** | 换手 ≤3% 且 振幅 ≤5% 且 量比 ≤1.0，且（获利盘 40-80% 或 贴近MA20） | 无脉冲、无扰动，适合中线，不适合做T | +1.48%/笔（n=454） |
| **HC-01 起爆资金** | 连涨 ≥2 且 量比 ≥1.2 且 当日涨幅 ≥3%，且（创20日新高 或 5日涨幅 ≥8%） | 动量确认，起爆入场 | **+6.17%/笔，胜率60.3%（最强属性，n=121）** |
| **YZ-01 游资主导** | 换手 ≥10%，且（振幅 ≥10% 或 涨停 或 连涨 ≥3） | 波动大、情绪化，席位反向指标（拉萨天团=卖出信号） | +0.98%/笔（n=358，无优势） |
| **DR-01 主力派发** | RSI6 ≥80 / 获利盘 ≥90% / 乖离 ≥15% 任一，且（放量 且 收盘日内下半区） | 顶部特征，减仓信号 | **−0.20%/笔，胜率37.9%（方向有效，n=29）** |

**半年确认的排序**：起爆日 > 慢资金日 > 游资日 > 派发日，四分类方向全部维持。

## 5. 评级与置信度校准（Signal 契约的两个字段）

借鉴 UZI-Skill 评审团机制与 aiagents-stock 分析师契约，收敛为四级评级：

| 评级 | 条件（同时满足） | 仓位系数 |
|---|---|---|
| **A** | 规则半年验证均盈亏 > 基准+1pp，且当日样本 n≥30，且资金属性匹配（HC-01） | 1.0 |
| **B** | 规则半年验证均盈亏 > 基准，且资金属性不冲突 | 0.8 |
| **C** | 规则方向为正但样本 n<30，或属性匹配度低 | 0.5 |
| **D** | 射程外/证伪规则/数据 suspect | 不出信号 |

`confidence`：high=多因子共振（≥2 个独立规则同向）；medium=单规则触发；low=规则触发但数据质量有瑕疵（suspect/stale）。

> 评级表随验证窗口滚动更新（见 06 回测规范 §4），**评级是历史统计的映射，不是未来收益承诺**。

## 6. 研究纪律（六条，全部来自踩坑史）

1. **当日可知**：信号日 T 收盘后计算，T+1 开盘成交假设；禁止用 T 日盘中/未来数据。回测与生产同一口径。
2. **窗口门槛 ≥6 个月**：3 个月窗口的 5 条结论在半年窗口翻转（docs/14 §0）——R06倒T、C02、R12 pre5、C05、C03预警版。**任何新规则必须 ≥6 个月窗口 + ≥120 交易日才准入规则库。**
3. **最小样本 n≥30**：低于此只记录观察，不进采纳配置（bias20≤-3% 仅 3 笔→不采纳；bull regime 26 笔→不启用）。
4. **双池验证**：主池（博主交易票）+ 扩展池（东财头部提股）分别计算，防单一池过拟合。
5. **证伪也要入库**：被证伪的设计写入规则库 `_falsified`，记录证据——防止未来重复"发明"已被证伪的想法。
6. **数据质量闸门**：suspect 数据不进信号计算；全源失败用缓存算信号但强制标注"数据陈旧至 X 日"。
