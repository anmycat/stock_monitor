# 00 · 总体设计与系统边界

> 版本：v1.0（2026-10-15）｜规则库：`rules/methodology_rules.json` v1.3｜验证基线：docs/14（半年实盘）

---

## 1. 系统是什么

把一个财经KOL方法论蒸馏体系落成**可执行、经实盘验证的信号生产系统**：

```
调研蒸馏（docs/01-13）→ 规则化（DSL规则库）→ 回测验证（双池+Kelly）→ 部署运行（ECS/FC）→ 推送人工执行
```

本目录（system/）是上述成果的**工程化重组**：不再按"某某博主"组织，而按**系统功能模块**组织。每份文档对应系统的一个功能面，全部结论可追溯到 `rules/methodology_rules.json` 与 `data/` 下的验证数据。

## 2. 系统边界

### 2.1 做什么
- 每日收盘后从行情接口拉取数据，计算指标，运行规则引擎产生**信号**（买入/卖出/观察/回避）
- 信号经 Kelly 仓位计算与风控过滤后，按 Signal 契约推送到钉钉/企业微信/邮件
- 跟踪用户成交回报，维护持仓状态机，盘中/持仓期持续给出持有/做T/离场建议

### 2.2 不做什么（明确边界）
| 边界 | 说明 |
|---|---|
| **不接入券商** | 不自动下单。系统生产信号，人工执行。执行闭环靠"成交回报协议"（见 07） |
| **不做全市场扫描（Phase 1）** | 候选池为固定 27 只（博主交易池+东财头部提股池），全市场扫描是 Phase 3 |
| **不做分钟级盘中预警（Phase 1）** | Phase 1 为日级批处理；分钟级迁 ECS 后才启用（见 09） |
| **不预测涨跌** | 系统输出的是规则信号与概率优势（胜率/盈亏比/Kelly），不是价格预测 |
| **不保证收益** | 全部规则经过实盘验证但有窗口依赖性，历史表现不预示未来 |

### 2.3 运行环境约束
- 部署目标：阿里云（ECS 常驻 或 函数计算 FC 定时触发，选型见 07/09）
- 数据通道：行情 HTTP 接口（东财 push2 主源，已本地验证可用）
- 无浏览器、无 MCP、无本地文件依赖（生产环境自包含）

## 3. 总体架构

```
┌─────────────────────────────────────────────────────────────┐
│ 调度层（cron / FC 定时触发器）                                  │
│   09:25 执行确认 │ 15:05 信号生成 │ 15:30 落库备份 │ 周日周报   │
├─────────────────────────────────────────────────────────────┤
│ 数据层（02）                                                  │
│   东财 push2 主源 → 新浪/腾讯备源 → SQLite 缓存兜底             │
│   不复权日K + 指数 + 基本面快照（PR用）                         │
├─────────────────────────────────────────────────────────────┤
│ 指标层（03）                                                  │
│   MA/RSI/KDJ/量比/换手 │ 筹码分布（自算）│ 资金四分类 │ regime │
├─────────────────────────────────────────────────────────────┤
│ 规则引擎（04/05）                                             │
│   资金识别4 + 交易6 + 风控过滤 + R11-R13 + 筹码C01-C05          │
│   射程匹配：规则 × 资金属性交叉矩阵，不在射程丢弃信号            │
├─────────────────────────────────────────────────────────────┤
│ 仓位层（06）                                                  │
│   Kelly f*=(bp-q)/b → 半凯利 → 相关性折扣 → 25%上限            │
│   负期望自动零仓位（R05 实测 f*=0）                            │
├─────────────────────────────────────────────────────────────┤
│ 输出层（07/08）                                               │
│   Signal 契约 → 推送队列 → 钉钉/企微/邮件 → 用户手机            │
│   成交回报协议 ← 用户回复 B/S 600xxx price qty                 │
└─────────────────────────────────────────────────────────────┘
```
