# 02 · 数据源与行情适配

> 版本：v1.0 · 2026-10-15
> 上游依赖：00（系统边界）、docs/09（回测口径）、docs/14（半年验证数据窗口）
> 本文定义系统吃什么数据、从哪来、口径是什么、挂了怎么办。**数据口径错误会让全部验证结论错位，是本文档存在的唯一理由。**

---

## 1. 口径总原则：与回测完全一致

全部规则（R01-R13、C01-C05）的回测验证基于 **不复权日K（adjust_type=0 / fqt=0）**，指标由日K自算。生产环境任何数据源、任何加工环节偏离这个口径，信号即失效。

| 维度 | 规定 | 违反后果 |
|---|---|---|
| 复权 | 一律不复权 | 前复权会改写历史价格，MA/RSI/筹码分布全部偏移 |
| 频率 | 日K（Phase 3 才引入分钟K） | 分钟K混入日K信号破坏"当日可知"纪律 |
| 指标来源 | 引擎自算（MA5/MA20/RSI6/KDJ_J/筹码分布） | 外部指标接口有陈旧快照风险（教训：neodata 估值快照 PE 错误，docs/11 §7） |
| 时区 | 东八区（Asia/Shanghai） | 跨日错位，信号日与成交日整体偏移一天 |

## 2. 数据清单

| 数据 | 用途 | 字段 | 频率 | 保留 |
|---|---|---|---|---|
| 个股日K | 规则引擎全部输入 | 开/高/低/收/前收/涨跌幅/振幅/成交量/成交额/换手率 | 每日 15:30 后 | 全量 |
| 上证指数日K | R13 牛熊指标（MA20/MA60/bias20） | 同上 | 每日 15:30 后 | 全量 |
| 基本面快照 | R11 市赚率（PE_TTM/ROE_TTM） | EPS_FY25、EPS_H1_26、EPS_H1_25、ROE 对应项、报告发布日 | 财报季更新 | 滚动 4 期 |
| 流通股本表 | 备源自算换手率 | 股票→流通股本 | 每周刷新 | 当前值 |
| 信号/成交记录 | SQLite 持久化 | 见 03 数据模型 | 实时 | 全量 + 每日 OSS 备份 |

**股票池**：主池 17 只（博主交易票）+ 扩展池 10 只（东财头部用户提股），共 27 只。池的构成见 05 策略矩阵 §2。

## 3. 主源：东方财富 push2

```
GET https://push2.eastmoney.com/api/qt/stock/kline/get
  ?secid=0.000011          # 0.=深市 1.=沪市（688 科创板也用 1.）
  &fields1=f1,f2,f3,f4,f5,f6
  &fields2=f51,f52,f53,f54,f55,f56,f57,f58,f59,f60,f61
  &klt=101                 # 101=日K
  &fqt=0                   # 0=不复权（与全部回测口径一致，禁止改动）
  &end=20500101&lmt=120    # 拉足够算 MA60/RSI6/KDJ_J 的历史长度
```

返回 `data.klines` 为字符串数组，每行 11 个字段：
`日期,开盘,收盘,最高,最低,成交量(手),成交额,振幅%,涨跌幅%,涨跌额,换手率%`

**换手率（f61）东财直给**，是筹码分布算法（C01-C05）的核心输入，不需自算。

### 3.1 盘中快照接口（Phase 3 分钟级预警用）

```
GET https://push2.eastmoney.com/api/qt/stock/get?secid=0.000011&fields=f43,f44,f45,f46,f57,f58,f60,f169,f170
```
Phase 1/2 不使用。**盘中不生成新信号**（见 07 执行与故障恢复 §3）。

## 4. 备源与兜底

### 4.1 备源清单

| 备源 | 接口 | 缺失字段 | 处理 |
|---|---|---|---|
| 新浪 | `money.finance.sina.com.cn/quotes_service/api/json_v2.php/CN_MarketData.getKLineData?symbol=sz000011&scale=240&ma=no&datalen=120` | 换手率/振幅/前收 | 用静态流通股本表自算换手率；振幅用高低自算 |
| 腾讯 | `web.ifzq.gtimg.cn/appstock/app/fqkline/get?param=sz000011,day,,,120,qfq` | 换手率 | 同上（注意其默认前复权，取 qfq 节点但只取价格结构，**仍需与东财不复权校准**） |

> 腾讯源默认返回前复权数据，接入时必须与东财不复权逐日比对校准（至少覆盖最近 20 个交易日），偏差 >0.5% 则弃用该源。

### 4.2 failover 链

```
东财 →（超时3s/解析失败）→ 新浪 →（失败）→ 腾讯 →（全失败）→ SQLite 本地缓存
```

- **缓存兜底**：全源失败时用本地最近数据算信号，推送卡片强制标注 `⚠ 数据陈旧至 YYYY-MM-DD`，宁可错杀不可静默
- **连续失败告警**：主备源全挂连续 2 个交易日 → 推送告警（防静默失效）
- **单只重试**：指数退避重试 2 次（300ms/900ms），仍失败记入缺口表，当日复盘可见

### 4.3 限流与防封

- 27 只逐个拉取，间隔 300-500ms；全池一次拉取约 10-15 秒
- **地域选择**：ECS 必须选华东/华北地域，海外地域访问东财有人机验证风控
- 不使用 akshare：上游接口一变整库崩且依赖重，与"指标自算、不信任外部快照"纪律一致

## 5. 数据质量闸门

每次拉取落库前过三道校验，任何一道不过则该只该日标记 `suspect`，不进入信号计算：

| 校验 | 规则 | 案例 |
|---|---|---|
| 逻辑校验 | 最高≥最低、最高≥开盘/收盘、最低≤开盘/收盘；OHLC 四价 >0 | 防脏行 |
| 跳空校验 | 开盘价与前收偏离 >±11%（非一字板）→ 标记人工复核（可能是除权或数据错误） | 除权日失真 |
| 单调性校验 | 与前一日收盘价偏离 >±11% 且非涨跌停 → 标记 | 停牌复牌异常 |

**除权日处理**：检测到除权（价格断层且成交额断层）时，该日及其后 1 日的信号标记 `div_adj`，当日可知指标（MA/RSI）照常计算但**筹码分布 D(t) 递推在除权日重置网格**（chip_distribution.py 已实现网格扩展逻辑，除权=价格区间整体跃迁）。

## 6. 时点纪律（与回测对齐的硬约束）

```
15:00 收盘 → 15:05 引擎读全量日K（含当日）→ 自算指标 → 生成信号（T日信号）
次日 09:25 推送执行提醒 → 用户开盘下单（T+1 成交）
```

- 信号日 T 的全部输入（当日 OHLC、换手率、指数、指标）在 15:00 后即完整可知，**不依赖任何未来数据**
- 成交价假设为 T+1 开盘价——与全部回测口径一致；盘中预警（Phase 3）只做"价格触及已生成信号的 entry_range"提醒，**不产生新信号**
- ECS 系统时区必须 `Asia/Shanghai`，cron 按东八区书写（见 07 §5）

## 7. 配置项

```yaml
data:
  primary: eastmoney_push2      # secid 规则：深市 0. 沪市 1.
  fallback: [sina, tencent]
  fqt: 0                        # 不复权，锁定
  klt: 101                      # 日K
  history_len: 120              # 覆盖 MA60 + 20日新高 + 5日量比
  request_interval_ms: 400      # 限流
  timeout_s: 3                  # 单源超时即 failover
  retry: 2
pool:
  main: config/pool_main.json   # 17 只
  ext: config/pool_ext.json     # 10 只
index:
  code: "000001.SH"             # 上证指数（R13）
  secid: "1.000001"
fundamentals:
  file: config/fundamentals.json # PE/ROE 快照，财报季更新
```
