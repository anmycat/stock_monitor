## 2. 游资操盘机制解析（暗盘/明盘框架）

### 2.1 两个口径的定义

- **明盘资金**：可见的主动成交（传统大单口径能捕获的委买委卖），同花顺按逐笔成交方向归类；
- **暗盘资金**：通过**大单拆单、隐性委托**推算的部分（基于 L2 逐笔成交数据的方向拆解，
  把"不易被传统大单口径判定为主动"的成交归入暗盘）。同花顺将该指标作为会员特色功能，
  本质是把**资金行为的隐蔽性**量化。

### 2.2 四类典型操盘模式（从榜单信号反推）

1. **暗盘吸筹 + 明盘拉升（启动前）**：暗盘持续净流入、明盘大单拉抬（如多伦科技 +10.06%
   暗盘+1245万/明盘+4424万，持续霸榜=多日出现在榜=资金持续）。
2. **暗盘逆势流入（吸筹/护盘）**：股价下跌但暗盘净流入（吉大正元 -5.11% 暗盘+2749万；
   凡拓数创 -1.89% 暗盘+3554万）——价格与隐蔽资金背离，是"谁在跌的时候接货"的直接答案。
3. **明盘流出 + 暗盘流入（派发掩护）**：大业股份 +1.57% 明盘**-9777万** 暗盘**+6802万**、
   冰山冷热 +1.86% 明盘**-10244万** 暗盘**+5995万**——明盘大单出货、暗盘拆单接盘的
   对倒结构，价格微涨是掩护。
4. **暗盘占比骤升（游资主导度）**：暗盘/成交额占比越高，短线资金主导越强，
   弹性大但持续性差（赛福天占比 22.87% 为样本最高）。

### 2.3 与项目已有方法论的同构性

D44 落地的 `_volume_position_score`（位置×量比矩阵：低位温和放量加分/高位剧烈放量
硬 veto）与"位置决定性质"是同一思想——**同样一笔放量，低位是吸筹、高位是派发**。
暗盘/明盘拆分相当于把"量"再切成"隐蔽的量 vs 暴露的量"两个维度，是该项目思路的
自然延伸，方向上不冲突。

## 3. 项目现状对比（代码实证 + 接口实测）

### 3.1 已有能力

| 能力 | 位置 | 说明 |
|---|---|---|
| 涨速异动监控 | `services/monitors/burst_monitor.py` | 活跃池 top300 成交额 + 涨速≥0.4% + 涨幅2-7.5% + 5分钟冷却 |
| 市场级异动 | `services/market/market_alert.py` | 涨停潮/普跌/量能暴增萎缩 |
| 日级资金流 | `data/sources/eastmoney.py: get_capital_flow` | 东财 fflow 日频（主力/大单/超大单），5 日累计 → `signals.capital_flow_5d` |
| 位置×量比 | `strategies/trend.py: _volume_position_score`（D44） | 低位放量加分/高位放量禁买 |

### 3.2 能力缺口（实测证据）

1. **暗盘/明盘拆分：数据不可得**。需要 L2 逐笔成交/委托数据，当前链路只有快照级行情
   （price/volume/change_pct）+ 日K。精确复刻同花顺暗盘资金**本轮不可行**。
2. **龙虎榜（游资营业部维度）：未接入**。API 实测 ECS 可用（见 §4.1），是**最近似
   游资操盘**的可得数据——营业部席位直接暴露"谁在买"（机构专用 vs 游资营业部）。
3. **盘中资金流在生产环境基本瘫痪**。东财 push2his/push2 从 ECS 实测 ConnectionError
   （出口 IP 被风控，12 §3.14 有记载）；`get_capital_flow` 静默降级返回 None——
   生产库 33 笔信号中 capital_flow_5d **仅 3 笔非空**。日级资金流字段目前形同虚设。
4. **板块资金流未接入**。新浪 MoneyFlow 接口实测 ECS 可用（概念板块净流入排名）。
5. ~~burst_monitor 活跃池板块失衡~~ **已修复（D45）**，见下节。

### 3.3 用户反馈二："推送全是科创板"——根因排查

**结论：数据解析缺陷（设计问题），不是阈值问题。**

- 现象：10-26 盘中异动推送 25 条全部为 688xxx（天准科技/博汇科技/当虹科技/中望软件/
  英科再生/品茗科技/步科股份/迪哲医药/概伦电子/道通科技/天智航/峰岹科技/奕瑞科技/
  均普智能/青云科技…），其他板块零曝光。
- 排查路径：生产日志 → burst_monitor 活跃池 → `refresh_active_pool` 成交额排序 →
  腾讯 `_parse_quote` volume 字段。
- **根因：腾讯 qt 接口成交量单位口径分裂**（2026-10-27 实测 12/12 样本零例外，
  仓库 fixture 复核确认）：
  - 科创板(688/689) `parts[6]` 原值即**股**；
  - 沪主板/深市/北交所/ETF `parts[6]` 为**手**。
  `amount = volume × price` 未做单位统一 → 科创板成交额虚高 100 倍 → top300 活跃池
  **299/300 被科创板霸榜** → 异动推送只出科创板。
- 本地复现（修复前）：top300 板块分布 `{688: 299, 300: 1}`。
- 修复（D45，已提交已部署）：`_parse_quote` 统一为「股」口径。修复后 top300：
  `{300: 58, 002: 58, 688: 46, 600: 42, 603: 25, 601: 25, 000: 24, 301: 15, 001: 3, ...}`，
  top10 为长鑫科技148亿/中际旭创134.8亿/新易盛109亿等真实成交额排名。
- 附带发现：10-27 信号少（6 笔）的另一半原因是 10:38 后市场转熊市门控跳过扫描
  （"Bear market, skip scanning"），属既有策略设计，非 bug。

### 3.4 对用户第一个反馈的回应

"没有发现这些游资类操盘"的准确表述：**系统的异动监控（burst）本来就在做"起爆资金"
监测，且 10-26 实际触发了 25 条——但因为 §3.3 的 bug 全部集中在科创板，其他板块的
游资异动被系统性掩盖**。修复后 burst 的板块覆盖已恢复正常；而视频展示的暗盘/明盘
维度、龙虎榜营业部维度，项目确实还没有（数据链路限制，见 §4 方案）。

### 4.2 方案清单（待用户裁定）

**P0 — 数据已验证可用、零新依赖**

- **M5-1 龙虎榜监控（游资操盘的核心抓手）**：每日盘后（约 18:30，数据收盘后 1-2 小时更新）
  拉取当日明细 + 按 TRADE_ID 拉席位明细；输出维度：
  - 机构专用 vs 游资营业部（建知名游资席位库，如各"拉萨/杭州/宁波帮"营业部）；
  - 净买额、买卖额、成交占比（DEAL_AMOUNT_RATIO）、上榜原因（EXPLANATION）；
  - 推送形态：并入既有 18:10 全日复盘之后的"龙虎榜日报"（单独消息，走 D44 节流合并）。
- **M5-2 资金流瘫痪排障（生产缺陷，建议优先于任何新功能）**：`get_capital_flow`
  当前静默降级不可接受——加 fill-rate 监控/告警；数据源换可达路径或降级为
  "仅 Redis 缓存命中时展示"。修复后 `capital_flow_5d` 才恢复意义，
  D44 的 `_volume_position_score` 也才能叠加资金方向确认（低位放量+主力净流入=吸筹确认）。
- ~~M5-3 burst 活跃池板块覆盖~~ **已完成（D45）**。

**P1 — 小开发量**

- **M5-4 板块资金流接入**（新浪 MoneyFlow.ssl_bkzj_bk）：概念板块净流入 top/bottom，
  与个股 burst 形成"板块→个股"传导视图；可与早盘/复盘总结合并。
- **M5-5 "逆势流入"近似信号**：日级口径 `涨跌幅<0 且 主力净流入>0`（等 M5-2 修复后），
  作为视频中"暗盘逆势流入"的粗近似；盘中口径暂不可得。

**P2 — 数据链路限制，本轮不立项**

- 暗盘/明盘精确拆分（需 L2 逐笔数据源采购）；
- 分钟级资金流曲线（EM 被墙，需换源或自建代理）；
- 游资席位持续性追踪（同营业部多日上榜）——依赖 M5-1 数据积累后再说。

### 4.3 与现有资产的兼容性

- 时间线：龙虎榜日报（盘后）与早间新闻（9:15）/早盘总结（12:10）/全日复盘（18:10）
  天然错峰，不冲突；
- 推送通道：统一走 D44 的 `send_signal` 节流 + `flush_signals` 聚合，不新增限流风险；
- 验证纪律：M5-1/M5-4 落地后按 D41 方式跑信号回归对比（历史日期双跑），
  确认不污染既有 signals 契约再上线。

## 5. 结论

1. **"推送全是科创板"是数据 bug**（腾讯成交量单位分裂，科创板虚高 100 倍霸榜活跃池），
   已修复上线（D45）；10-27 信号少另有熊市门控因素，属策略设计。
2. **游资监控的最近可行路径**：龙虎榜（API 实测可用，营业部维度直接暴露资金主体）
   + 资金流瘫痪排障 + burst 板块覆盖修复（已完成）。暗盘/明盘维度受数据链路限制
   只能以"龙虎榜+日级资金流+逆势流入近似"组合逼近，精确复刻需 L2 数据采购。
3. 建议用户裁定：M5-1（龙虎榜日报）与 M5-2（资金流排障）是否立项；M5-2 虽不性感，
   但它是所有资金面能力的地基。
