## 三、核心结论速览

### 静水2008 —— 可蒸馏出完整方法论 ✅

- **定位**：基本面驱动的**景气成长股趋势投资者**（非价投，自称趋势投资）
- **总纲三步**：刻意思考 → 财报期地毯式扫描 → 反人性持盈
- **最鲜明立场**：**择股 > 择时**，主张彻底摒弃技术分析（缠论/波浪/均线）
- **财报 SOP**：业绩 → 增长原因 → 个人看法；核心判据为扣非/归母、低基数、并表剥离、现金流收现比、周期 vs 稳态
- **风控规则**：回调分仓分批买入 + 预设止损位坚决砍 + **不止盈** = "止损不止赢"
- **周期观**：万物皆周期；**顶是跟出来的不是预测出来的**；高切低是伪命题；不恐高
- **可计算化程度高**：多数判据可直接映射为量化筛选条件

### 多空博弈社 —— 无成体系方法论 ⚠️

- **定位**：超高频、超短文本的**情绪喊单型**短线账号
- **行为**：299 篇全为 1–3 句情绪喊话；标的集中度极高（中毅达 28%）；盘中刷屏
- **叙事**：主力 vs 散户筹码博弈（不可证伪框架）；与上市公司停牌制度直接对抗
- **方向一致性**：看多 35% / 看空 34%，几乎无方向框架
- **快手实盘对照**：文字喊“中毅达”，实际交易重心在**香江控股、爱丽家居、百合花、新金路、红宝丽**；大号（江海证券 0857）晒成交明细，小号（东方财富）晒亏损持仓
- **实盘比对结论（新增，见 06 号文档）**：用 NeoData 不复权日K逐条校验 84 笔交易——
  - **截图价格 100% 真实**（75 笔成交价全部落在当日真实 [最低,最高] 内，0 笔超出）→ **不是 P 图，不能靠"价格离谱"识别他**
  - **择时能力 ≈ 0**：买入平均买在当日振幅 49.6% 位置、卖出 50.6%，跑不赢"拿到收盘"（+0.31% / +0.04%）
  - **做 T 不赚钱**：同日配对 9 笔平均 +0.41%，最大单笔 -6.52%（开盘追高、1 小时后地板价割肉）
  - **钱是"捂住"赚的**：剔除 2 笔持股 4–8 天赶上涨停的单子后，其余 18 笔平均只剩 +0.19%
  - **最大风险是单笔重仓割肉**：远东股份 -17.57%，占总亏损 47%
- **决策逻辑推导结论（新增，见 07 号文档）**：对 82 条可分析动作规则化反推"他为什么在这个点做这个动作"（16类买入/12类卖出理由）——
  - **盈利来源**：连涨2-5日追涨（9条，次日均值+3.4~+6.6%，胜率75-100%）、涨停开板低吸（+3.60%）、倒T先卖后买（7组全胜+1.19%）、连涨后兑现（+2.93%）
  - **亏损来源**：深跌低吸/跌停博弈（8条，-5.03%，胜率仅12%）、强势中追涨（-3.33%）、打板（-8.50%）、无理由随手单（-3.04%）
  - **分水岭是动量确认**：同为追涨，"连涨N日追涨"大赚 vs "单日大涨半路杀入"大亏
  - **规则执行不一致**：8/28连涨4日乖离+29%坚决兑现（正确）vs 9/14涨停高乖离选择"再拿拿"次日跌停-10.01%
- **价值定位**：不建议作为策略来源；**可作为"散户情绪/反向指标"另类数据、"风险账号识别"训练样本，以及"文案-交易一致性"检测样本**；其"连涨追涨+做T"模式可作为动量策略的实盘参照样本

可拆解为 4 个模块：

1. **财报超预期扫描器**
   - 输入：全 A 财报（营收/扣非/归母/现金流/毛利率）
   - 规则：扣非增速阈值 + 超一致预期 + 剔除低基数 + 剥离并表
   - 输出：每日"超预期公司清单"（对应她的"超预期财报跟踪"日更）

2. **财报质量打分器**（对应她的判据表）
   - 质量分：扣非/归母、现金流/净利、毛利率变化、业务集中度
   - 持续分：周期性标记、产能供给前瞻、下游景气
   - 商业模式分：设备/耗材/卖铲人 > 硬件 > 封测/券商

3. **行业景气度排序器**
   - 行业内超预期公司数量占比 + 增速中位数 → 景气排名
   - 叠加拥挤度（换手率、成交额占比、估值分位）→ 触发"过度拥挤"预警

4. **个股观点知识库**
   - 以 `stock_views.csv` 为初始种子，持续增量抓取
   - 支持按标的/时间/立场检索，供人工复核

### 5.2 若做"内容/账号风控" → 以多空博弈社为反面样本

- 用第 02 号文档第 7 节的 7 条特征做规则引擎（标的集中度、多空词比、挑衅词占比、文本长度、盘中占比、量化要素缺失、自证式表述）
- 叠加快手视频特征：文案-交易标的偏离度、持仓页 vs 成交明细页比例、亏损账户展示频率
- **⚠️ 不要用"截图价格是否离谱"识别他**：06 号文档实测，其 75 笔成交价 100% 落在当日真实 [最低,最高] 区间内，截图不是 P 的。有效判据是**喊单标的与实盘标的重合度**（本例 0%）与**交易频率 vs 收益集中度背离**（高频交易但 52% 盈利来自 2 笔）
- 输出：账号可靠度评分

### 5.3 若做"情绪因子"→ 用多空博弈社数据做实证

- 将其 299 条按时间对齐个股分钟/日线，检验**发帖强度与情绪极性**对次日收益的预测力
- 若显著为负 → 作为反向指标因子
- **补充可用信号**（来自 06 号文档）：他的买入平均落在当日振幅 50% 位置、卖出无章法，因此其**晒盈利单的时点往往对应个股短期情绪高点**，可作为散户情绪温度的输入

### 5.4 总体架构：采用"多博主智能体 + 评审团共识"（08 号文档落地建议）

```
博主方法论库（skill YAML 化：静水2008/多空博弈社/东财头部×N）
        │
        ▼
每个博主一个 analyst agent（带数据白名单+射程定义+语言风格样本+历史准确率）
        │
        ▼
consensus 汇总 + 分歧检测 → rating/confidence/entry_range/take_profit/stop_loss
```

1. **方法论资产 YAML 化**：对标 daily_stock_analysis 格式（name/category/core_rules/instructions），每位博主一个 YAML
2. **射程预过滤**：每个博主只对能力圈内的票输出观点（否则 consensus 被噪声淹没）
3. **confidence 四级校准**：85-100 硬指标全命中 / 60-84 多数命中 / 30-59 部分命中 / 0-29 不适用
4. **历史准确率权重**：复用 docs/07 的 price→次日收盘方法，给每个博主维护观点准确率档案
5. **分歧即信号**：多博主 Signal 打架时输出分歧度而非强行共识

### 5.5 实盘模拟验证结论（09 号文档，方法论核心）

**五层体系**：资金识别（慢资金/起爆/游资/派发）→ 射程匹配 → 信号规则（R01-R06）→ Kelly 仓位 → 风控纪律（R07/R08/R10）。

| 验证发现 | 数据 |
|---------|------|
| 起爆资金 vs 游资盈亏方向相反 | R02 涨停开板低吸：起爆日 +17.24%(n=3) vs 游资日 -4.62%(n=5) |
| 规则有射程，不在射程必须丢弃 | 倒T：无属性日 +0.56%(n=55) vs 起爆日 -9.04%(n=9)；R04 主池 +1.12% vs 扩展池 -1.82% |
| Kelly 自动给负期望规则零仓位 | R01/R05/主池R06 期望为负→停用；正期望规则修正仓位 2.4%~12.1% |

### 5.7 三条新规则实盘验证结论（11 号文档，2026-07-06~10-13 三个月）

**规则库升至 v1.1（13条规则）**。验证方法：216笔规则信号 + 博主43笔真实买入，PR为point-in-time（中报发布前FY25口径/发布后滚动TTM），regime取信号日上证指数。

| 规则 | 验证结论 | 关键数据 |
|------|---------|---------|
| R11 市赚率 | **选股负面清单100%有效，信号闸门证伪** | 博主43笔买入100%命中回避带(17笔23.5%胜率)/亏损带(26笔)；27只仅中际旭创0.64、中信0.74在观察带；按它过滤信号216→6笔。射程：中线价值选股前置，禁作动量硬闸门 |
| R12 预期差 | **对人类追涨有效，对动量规则反效果，须分射程** | 博主"透支追入"7笔胜率0%、均-4.14%；规则信号pre5>10%组反而+1.87%（连涨即动量信号本身）。射程：R04及事件驱动默认开启，禁用于R01/R02/R06 |
| R13 牛熊指标 | **原设计（熊市禁开仓）证伪；改造为"急跌禁低吸"后显著有效** | 熊市37天贡献+114.46%全部利润，禁开仓使+25.47%→-88.99%；变体idx_bias20≤-2%禁R05：+25.47%→+63.64%，被禁10笔胜率10%（8笔止损） |
| 组合 | **三条当全局硬闸门齐上=证伪（216→2笔，-4.04%）；修复后采纳配置（R12默认+R13急跌变体）=累计+64.21%、胜率49.7%** | 基线+25.47% |

**验证过程修复4个bug**：①PR公式实现错100倍（可口可乐0.474校准复核后修正）；②规则ID比较误用字典键名致变体过滤落空；③neodata估值快照陈旧（PE改自算）；④急跌阈值-3%过严改-2%。

**方法论沉淀**：规则必须做**射程界定**（选股层/信号层/环境层分离），"蒸馏出的规则"≠"可全局堆叠的闸门"——本项目已建立"规则→实盘验证→射程修订"的闭环流程（scripts/validate_new_rules.py 可复用于后续新规则）。

## 六、工程化经验（踩坑记录，供后续扩展抓取复用）

| 平台 | 难点 | 解法 |
|---|---|---|
| 雪球 | 阿里云 WAF，curl/headless 均被拦截 | **必须真实浏览器**（`scripts/cdp.py`）加载一次页面，再在页面上下文内 `fetch` 站内 API（`/v4/statuses/user_timeline.json`、`/statuses/show.json`） |
| 知乎 | 搜索/API 需登录态 | 同理，浏览器登录后页面内 `fetch` `/api/v4/members/{token}/answers` 等接口 |
| 东方财富 | 创作平台为 JS 渲染 | 先用 `performance.getEntriesByType("resource")` 定位 JSONP 接口 `gbapi.eastmoney.com/userpostlist/api/UserPost/CenterList`，再用 `requests` 直连（无需登录） |
| 快手 | 作品列表接口统一风控 | 主页列表未解；**单条分享短链 `v.kuaishou.com/xxxx` 可解**——桌面登录态打开后拦截 `graphql/vision` 接口取元数据，再下载 atlas/cover 图集 |

**CDP 使用要点**（已在 `scripts/cdp.py` 内固化）：
1. Chrome 需带 `--remote-debugging-port=9222 --user-data-dir=<独立目录>` 启动；
2. 新版 Chrome 创建标签页须用 **PUT** `/json/new`；
3. WebSocket 握手须 `suppress_origin=True`，否则 403。
