## 一、调研：筹码峰战法的方法论原型

### 1.1 静神00988 八形态（原文蒸馏）

| # | 形态 | 静神原文要点 | 操作含义 |
|---|---|---|---|
| 1 | 低位单峰密集 | 窄幅箱体震荡吸筹，峰越厚吸筹越充分，**放量突破单峰上沿→及时跟进** | 买入 |
| 2 | 高位单峰密集 | 上涨后高位横盘+放量，**主力派发信号，及时离场** | 卖出/回避 |
| 3 | 双峰密集 | 箱体上下两峰，箱体内高抛低吸，底部阶段蕴含吸筹意图 | 做T/观察 |
| 4 | 上涨多峰密集 | 上涨中每次回踩形成小山峰，有资金承接抛压 | 持股（洗盘） |
| 5 | 下跌多峰密集 | 下跌中每次反抽诱多形成小峰，规避 | 回避 |
| 6 | 上峰不移 | 派发后回落但上方筹码未松动，套牢盘沉重，后市阴跌 | 回避 |
| 7 | 下峰锁定 | 上涨中最下方小峰未明显缩短，主力锁仓，**可及时跟进** | 持股/买入 |
| 8 | 筹码发散 | 杂乱无章无方向，主力未高度控盘，观望不参与 | 回避 |

### 1.2 算法口径（通达信官方《移动筹码分布》）

```
递推式：D(t) = D(t-1) × (1 - turnover(t)) + TriCost(t) × turnover(t)
TriCost：当日换手筹码在 [最低价, 最高价] 之间，以中价（成交额/成交量）为峰做三角形分布
派生：获利盘比例 / 平均成本 / COST(5)~COST(95) 90%成本区间 / 集中度=(COST95-COST5)/中值×100
```

"90比3"锁仓判据（市值风云算法梳理）：**90%筹码已获利 + 换手<3% = 本该卖出的人没有卖，只有集中锁仓的筹码能解释这种沉默**。

## 二、算法实现与交叉验证

`scripts/chip_distribution.py` 按上述口径实现，三个关键工程决策：

1. **密度守恒的网格扩展**：价格超出既有网格时重建网格，旧分布按"密度=值/格宽"插值，防止网格变宽后旧筹码面积缩水
2. **按价格位置注入**：当日三角形成本必须映射到全局网格的对应价格区间，不能按索引直加（否则筹码铺满全区间）
3. **初始假设**：窗口首日全部流通盘=当日三角形分布。63个交易日、日均换手5-15% 下残留<5%，影响可忽略

**交叉验证（49条带东财筹码接口值的博主动作）**：

| 指标 | 平均绝对误差 | ≤5误差占比 |
|---|---|---|
| 获利盘比例 | **2.06pp** | 90% |
| 平均成本 | 3.06%（相对） | 67% |

自算筹码与东财接口口径一致，算法可信。

**合成场景健全性测试**（全部符合理论预期）：横盘→单峰密集获利盘50%；一字板→获利盘100%主峰锁低位；高位放量滞涨→筹码上移获利盘≈51%；箱体→双峰+峡谷；高位跌回→获利盘24%双套牢峰。

## 三、C01 经典场景诊断：零触发

静神原版 C01（集中度≤15 + 单峰 + 峰位≤0.5 + 放量突破主峰上沿）的触发漏斗：

```
432样本 → 集中度≤15: 67 → 单峰: 30 → 低位(峰位≤0.5): 1 → 前日收盘在峰内: 1 → 突破上沿: 0 → 放量: 0
```

**结论：本批博主交易过的高波动题材票（集中度中位25.8、峰位中位0.59、单峰占比仅14%）不存在"低位单峰密集后突破"的场景**。这是射程外，不是规则失效——C01 的正确用法是在全市场横盘筑底票中筛选，而非在已异动票上找买点。

## 四、筹码画像 × 未来收益（分带研究）

基准（每天都买入，持有5日）= **-2.43%**（本批票最近1个月整体下跌，跑赢基准即有效）。

### 4.1 一维分带

| 维度 | 分带 | 持有5日 | 持有10日 | 判读 |
|---|---|---|---|---|
| 集中度 | ≤10 | -0.25%(5) | -0.45%(2) | 最集中=最抗跌 |
| | 10-20 | -2.36%(57) | -7.76%(25) | |
| | 20-30 | -1.07%(73) | -1.26%(37) | |
| | 30-50 | -1.75%(48) | -2.55%(24) | |
| | >50 | **-6.41%**(37) | **-11.95%**(17) | 高度发散=大幅跑输 |
| 获利盘 | ≤30% | -1.45%(96) | -3.13%(52) | 抛压衰竭有一定支撑 |
| | 30-60% | -4.11%(54) | -8.01%(24) | |
| | 60-85% | -1.46%(31) | **+2.18%**(13) | 10日唯一正值 |
| | ≥85% | -3.28%(39) | **-11.19%**(16) | 极端获利=兑现风险 |
| 峰位 | ≤0.3 | **+0.59%**(63) | **+0.60%**(31) | 低位=唯一正值 |
| | 0.3-0.6 | -0.77%(60) | -3.15%(32) | |
| | 0.6-0.9 | **-5.38%**(90) | **-10.55%**(40) | 高位=大幅跑输 |
| | >0.9 | -5.93%(7) | -0.85%(2) | |

**一维结论**：三个维度中**峰位（主峰在60日区间的位置）判别力最强且单调**——低位唯一为正、高位大幅为负。集中度与获利盘方向符合战法叙述，但会被位置混淆（见4.3）。

### 4.2 二维交叉：峰位 × 获利盘（核心证据）

| 峰位\获利盘 | ≤30% | 30-60% | 60-85% | ≥85% |
|---|---|---|---|---|
| **≤0.3（低位）** | -1.40(31) | -2.35(16) | **+6.02(7)** | **+8.44(9)** |
| **0.3-0.6（中低）** | -1.30(30) | -1.20(10) | **+5.84(9)** | -4.34(11) |
| **0.6-0.9（高位）** | -1.88(30) | -5.05(26) | **-9.33(15)** | **-8.22(19)** |
| >0.9（顶部） | -0.13(5) | — | — | — |

**这是本次检验最重要的发现**：

- **同一个"获利盘≥85%"，在低位是+8.44%（全场第二），在高位是-8.22%（全场最差）——相差16.7个百分点**。位置决定性质：低位高获利=突破完成、上方无套牢盘；高位高获利=派发尾声、随时崩塌
- **低位+获利盘60-85%（突破确认态）**：+5.84~+6.02%，超额近8.4pp
- **高位任何组合全部为负**（-1.88~-9.33%）：峰位>0.6 是硬性回避区

### 4.3 二维交叉：峰数 × 峰位

| 峰数\峰位 | ≤0.3 | 0.3-0.6 | 0.6-0.9 | >0.9 |
|---|---|---|---|---|
| 1峰 | -9.03(5) | -1.49(8) | -4.31(24) | — |
| 2峰 | -10.28(14) | -1.46(29) | -2.44(27) | -5.93(7) |
| 3峰 | +0.40(27) | +1.13(22) | -10.43(27) | — |
| **≥4峰** | **+12.66(17)** | — | -2.78(12) | — |

- **低位多峰≥4 = 全场最佳组合（+12.66%，超额15.1pp）**：资金在低位反复承接、收敛在即（对应静神形态4"上涨多峰=洗盘承接"与"多峰→单峰=吸筹"论）
- **一维"集中度越低越好"被修正**：低位单峰反而-9.03%（可能是下跌中继的跌透横盘，趋势未反转），说明**位置+形态组合才有效，任何单维阈值都会误判**

### 4.4 关键组合汇总（持有5日）

| 组合 | n | 均值 | vs 基准 |
|---|---|---|---|
| 低位+多峰≥4（吸筹收敛态） | 17 | **+12.66%** | +15.1pp |
| 低位+获利盘60-85%（突破确认态） | 16 | **+5.92%** | +8.4pp |
| 低位+获利盘≥85%（突破完成态） | 20 | +1.41% | +3.8pp |
| 高位+单双峰（派发完成） | 7 | -5.93% | -3.5pp |
| 高位+获利盘30-60%（半山腰） | 28 | -6.15% | -3.7pp |
| 高位+获利盘≥85%（派发态） | 19 | **-8.22%** | -5.8pp |

## 五、C02 派发预警与博主对照

### 5.1 派发预警（获利盘≥85% + 放量滞涨）

| 版本 | n | 随后5日 | 随后10日 | 下跌占比 |
|---|---|---|---|---|
| 仅获利盘≥85% | 39 | -3.28% | -11.19% | 54% |
| +5日涨幅≤3%（滞涨） | 8 | **-5.74%** | **-16.66%** | 62.5% |
| +放量（量比≥1.2） | 0 | — | — | — |

滞涨版方向有效（样本小）；再加放量后零触发——本批票的派发多伴随缩量阴跌而非放量滞涨。

### 5.2 博主82条实盘动作对照（独立验证样本）

| 画像 | 集中度中位 | 获利盘中位 | 峰位中位 | 单峰占比 | C01形态命中 |
|---|---|---|---|---|---|
| 全样本基准 | 25.8 | 18% | 0.59 | 14% | — |
| 博主买入日（43笔） | 64.1 | 64% | 0.71 | 14% | **0%** |
| 博主卖出日（38笔） | 65.3 | 73% | 0.70 | 18% | 5% |

- **博主买入集中在"高位+高获利盘+发散"态，与筹码峰战法"低位单峰密集才跟进"完全相反**——博主不按筹码战法选股（与 docs/07"盈利来自动量确认、亏损来自深跌低吸"结论互证）
- 博主买入次日收益×获利盘分带：≤30% 组 **+0.25%**（唯一正值），30-60% 组 -2.92%，60-85% 组 -1.79%，≥85% 组 -0.47%——**博主在低获利盘（抛压衰竭）时买入，次日表现最好**，部分支持筹码逻辑

## 六、被证伪/废弃的设计

| 原设计 | 检验结果 | 处置 |
|---|---|---|
| C01原触发条件（集中度≤15+单峰+突破上沿+放量） | 432样本零命中 | 射程外；形态逻辑由新版C01（低位+获利盘60-85%状态识别）承接 |
| C04"上峰保留率≥0.8%不移"过滤 | 剔除后基准-2.43%→-3.04%，无增量 | 废弃，改为峰位口径C04 |
| C06"集中度>25或峰数≥3=发散=观望"禁买 | 发散样本-2.05% vs 基准-2.43%；低位多峰≥4为全场最佳+12.66% | 废弃——**发散≠回避，低位发散是吸筹** |
| 一维"集中度越低越好" | 被二维交叉修正 | 集中度退为辅助维度，峰位优先 |
| 衰减系数 decay=0.5/1/2 | 集中度读数±50%偏移，收益结论方向不变 | 按decay=1.0校准阈值 |

## 八、局限性声明

1. **窗口仅1个月/20个交易日/27只票**：432样本中关键组合n=7~28，统计显著性不足；C05（n=7）为弱证据
2. **本批票射程偏斜**：全部是博主/东财头部交易过的高波动题材股，整体处于下跌通道（基准-2.43%），"低位吸筹"场景天然稀缺；结论不可外推到横盘筑底票占多数的全市场
3. **筹码分布是估算非真实持仓**：三角形分布+换手衰减是统计近似，限售股/锁仓股不参与计算；初始假设（窗口首日全流通=当日成本）对低位峰有轻微污染
4. **峰位依赖60日区间定义**：窗口初期（7月）的60日区间不完整，早期样本峰位读数偏高
5. **未检验做T维度**：静神形态3"双峰高抛低吸"需要日内数据，本次只做了选股/禁买层

**下一步**：回测池扩容到100+只/12个月后复测（尤其补充横盘筑底票，让C02吸筹收敛态有足够样本）；分钟数据到位后检验双峰做T；将筹码指标接入 ECS 部署方案的规则引擎（docs/12 §5.2 表格已预留位置）。
