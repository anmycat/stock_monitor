她在《大家认为交易中最难的是哪个环节？》《如何看懂财报分析？》等回答中把整套体系概括为**三步**：

```
第一步：刻意思考      —— 建立"必须找到超级成长股"的观念，并让它支配日常投研行为
        ↓
第二步：地毯式寻找    —— 每个财报期全市场扫描，绝不漏掉一只超级成长股

第三步：驾驭成长股    —— 反人性持盈，"死死咬住，一口气吃成胖子"
```

她强调：**"大智若愚，大巧若拙"——真正有用的就是不起眼的、日复一日的寻常工作（读财报）。**

## 三、投资风格定位：三层分类中的"趋势投资"

在《股票投资如何实现财富自由？》中她给出明确分类与取舍：

| 类型    | 她的判断     | 理由                                                       |
| ----- | -------- | -------------------------------------------------------- |
| 超短线   | **放弃**   | "和赌博差不多，没几个人能走出来，我和身边做大的没有靠超短线的"                         |
| 趋势投资  | **✅ 采用** | "不需要你思考，只需要你看见并跟随"，最省精力、最可复制                             |
| 纯价值投资 | **放弃**   | "你的认知不足以对事物长期有清晰认知，你也很难对大多数公司科学估值……你买到的看似便宜其实是垃圾，只会越跌越贵" |

**趋势投资的操作定义（她的原话提炼）：**

1. 问自己：当下什么行业最景气、社会讨论度最高、政策明显倾斜、**最重要的是有实打实业绩**；
2. 在该行业中选"核心最受益 + 市场最认可"的标的，盯住；
3. **找回调机会，分仓分批买入**（不追高，用回调保证胜率）；
4. **买入即设止损位**，到点坚决砍，"无论别人怎么说，无论你脑海怎样想"；
5. 盈利后**不止盈**，让利润奔跑；
6. 核心心法 = **"截断亏损，让利润奔跑"**，即"**止损不止赢**"。

## 四、核心信条（可直接作为规则化的断言）

### 4.1 择股 > 择时（最鲜明的立场）

她专门撰文论证"缠论必败"，并把该逻辑推广到**一切技术分析**：

- 缠论的 bug 不是理论不精密（恰恰相反，它逻辑自洽、无法被证伪），而是**占用了人的注意力**；
- "人是一种专注性动物"，专注技术分析就必然轻视择股，而**择股才是主宰股价未来变动方向和力度的核心要素**；
- **择股与技术分析择时不相容**——真去找超级成长股，就一定会轻择时；
- 结论："想赚到 A8/A9/A10，必须和技术分析说拜拜，越早越好。"
- 对教技术的老师："人家教的都是对的啊！！！这才是最可怕的……它们在市场上赚不到大钱啊，没有赚你们学费来钱快啊！！！"

### 4.2 万物皆周期，顶是"跟出来"的不是"预测出来"的

《财经大v的陨落》是她方法论的关键文本：

- 行业大 V 一批批陨落的根因：**"万物皆周期，股价只跟随公司基本面的业绩增速同向波动"**；行业增速到达极值后必然回落，大 V 无法脱离行业单独存在；
- 幸存者（10%）的特征：**"不拘泥于单一行业，而是日复一日对整个市场的景气预期进行检视"**，快速形成对未知行业的正确认识并计算景气上行区间，在行业顶峰初期或下降初期带着丰厚获利离场；
- **"顶，从来都不是预测出来的，而是跟出来的"** —— 泡沫何时破只能等它破的时候才知道，"所有国际大投行都把握不准"；
- **"高切低从来都是伪命题"** —— 资金只追随高成长，"你低位下行周期，我赚够了米，为什么要去接你这个盘"；
- 例外：被错杀的超级成长蓝筹，价投成长投资者不会放过。

### 4.3 不恐高：好东西从来不便宜

《ai泛科技三年大牛市小结》：

- 类比买房：2005–2021 核心商圈 vs 郊区 → 超级成长 vs 垃圾股；
- "每一次核心成长下跌时，你从概率角度看，都极难买到最高点，但是你怕，你恐高"；
- "散户想赚钱，先把恐慌治好了，因为这个世界上，好东西从来就不便宜"；
- 案例：光之王（中际旭创）100 多元时市场主流声音是"科技股都是垃圾，要拥抱核心资产（白酒）"，结果涨到 1200 多元；
- 提出"**小登股**（AI 泛科技）vs **老登股**（白酒大消费）"的市场结构判断。

### 4.4 只做简单题，不做难题

- "有过长期投资经验的投资人会知道，一个行业到了当下这个时间点，投资是最难做的，**不要做难题**"；
- "**好马不吃回头草**"——已获利的板块不再回头参与；
- 高位拥挤 + 业绩兑现 = 危险组合："过度拥挤＋中报兑现，一波杀下来"。

## 五、财报分析 SOP（她日常真正执行的工作流）

这是她**最高频、最可复制**的部分。每篇"超预期财报跟踪"都严格遵循三段式：

```
【业绩】营收/扣非归母 + 同比增速      ← 定量事实
【增长原因】量/价/结构/产能/并表拆解   ← 归因
【个人看法】质量判断 + 持续性 + 参与意愿 ← 定性结论
```

### 5.1 关键判据（可量化）

| 判据              | 她的用法                         | 典型表述                                         |
| --------------- | ---------------------------- | -------------------------------------------- |
| **扣非 vs 归母**    | 用扣非判断主业真实质量，归母里的投资收益/持股浮盈要剥离 | "扣非比归母更能说明问题""归母里另有约 22 亿持股长鑫浮盈，不计入扣非"       |
| **低基数排除**       | 高增速要回溯去年同期基数                 | "但高增含低基数（去年扣非仅 5.44 亿）"                      |
| **并表/并购成分剥离**   | 区分内生成长与外延并表                  | "增速字面最高但并表成分重，看 Q3 能否靠主业延续"                  |
| **毛利率变化**       | 判断是量增、价增还是结构升级               | "毛利率从 37% 跳到 63%"                            |
| **现金流 / 收现比**   | 验证利润是否变成真金白银                 | "现金流上半年还是 -4435 万、收现比才三成，说明涨价红利还没完全变成真金白银回款" |
| **周期性 vs 稳态成长** | 周期品的高增不可线性外推                 | "大概率是价格高位震荡下的高波动盈利，而不是消费股那种线性持续增长"           |
| **业务单一度**       | 集中度高 → 波动大                   | "公司盈利 99% 押在 VC/FEC 上、业务单一"                  |
| **产能/供给前瞻**     | 预判价格拐点                       | "下半年行业新建产能……一旦供给宽松、价格回落，单吨毛利就会从 9 万向下缩减"     |

### 5.2 商业模式偏好（明确的红黑榜）

**偏好（"卖铲人"逻辑）：**

- **设备类 > 硬件类**："当下对设备标的好感度要好于硬件链，设备股财报还是很清爽的"
- PCB 产业链（钻针耗材、钻机设备、电子布、树脂）
- 光模块/光器件上游
- 半导体设备（中微、拓荆、大族数控）

**回避：**

- 封测："我一直不是很喜欢封测的商业模式"
- 券商/金融科技（东财、同花顺）："本质是市场温度计……不是脱离大盘能独立长大的成长股"
- 二线成长、蹭概念："不参与这种二线成长"
- 下行周期中的"便宜"标的（如五粮液）："我为什么要去博弈呢"

### 5.3 五档表述体系（可作为标注 schema）

从她的"个人看法"中可稳定抽取五类结论：

1. **认可并参与**（少量）：财报质量高 + 景气持续 + 位置合适
2. **认可但只跟踪**（最多）："当下还是跟踪状态""等新催化"
3. **认可但不参与**（多）："好马不吃回头草""没有参与欲望"
4. **中性观察**："观看与跟踪，但不参与"
5. **明确回避**：商业模式不喜欢 / 周期不可持续 / 位置太拥挤

> 语料统计（结构化观点库 213 条）：偏多 106、中性/观察 73、偏空/回避 34。  
> **关键洞察：她"看好"的比例远高于"买入"，说明财报跟踪是选股漏斗，而非交易信号。**

## 七、六项能力模型（《为什么更多人喜欢做日内交易而不做大的趋势？》）

她认为做大趋势需要六项素质，每缺一项就淘汰一大批人：

1. **找到超级成长股的能力** —— 需要行业高认知与高敏锐度（举例：段永平懂消费电子→苹果；她玩摩托车懂行业→2019 春风动力）
2. **耐心跟踪基本面变化的能力** —— 分辨影响股价的**主要矛盾 vs 次要矛盾**
3. **克服止盈心理、持盈的能力**
4. **甘愿回撤、从头再来的能力**
5. **杀伐果断、看错就砍的能力**
6. **搭建完整投资体系、不受他人干扰的能力** —— "投资就是构建一张大拼图的能力，95% 的人都没有"
