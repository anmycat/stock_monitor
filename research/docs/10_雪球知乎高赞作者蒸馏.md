## 二、发现链路（可复用的作者挖掘方法）

### 2.1 知乎：热题评论区挖掘（375 位候选）

```
本地 257 个问题ID（静水回答过的）→ 筛 103 个股票投资类 → CDP 抓问题页 SSR
  → .ContentItem 卡片提取 data-zop(authorName/title) + data-za-extra-module(upvote_num)
  → 按 总赞+最高赞×3+答题数×500 排序
```

**关键经验**：
- 知乎问题页 SSR 无需登录即可抓（登录态在浏览器里也有效），未登录只显示前 5 个回答，**滚动可触发加载到 20+ 个**
- 跨域导航（雪球 tab → 知乎）会触发人机验证页（`/account/unhuman`），**必须先访问目标域首页建立上下文**
- 高频连续请求会软风控（重定向首页），**每作者间隔 5 秒+独立 tab** 可稳定跑完 19 人
- 部分账号已注销（么么哒一度重定向，赛博格Cyborg 后期不可用）——**用 URL 是否保持在 /answers 检测**

### 2.2 雪球：热门股票页讨论区挖掘（71 位候选）

```
18 只热门股（茅台/宁德/平安/东财/中际旭创…）→ CDP 抓股票页 SSR
  → a[href*="/u/"] 作者卡片（文本含"XXX粉丝、N条相关讨论"）
  → 聚合粉丝规模+讨论数+覆盖股票数
```

**关键经验**：
- `user_timeline` 接口已收紧（**只返回最新 7 条**，分页失效），friendships/profile/search 全被 WAF——**股票页 SSR 是当前唯一可用的作者发现源**
- 卡片文本偶发数字连排 UI bug（"伊飞2020132281粉丝"），**粉丝数以 user_timeline 的 user.followers_count 为准**
- comments 接口可用，可作补充链路

## 四、可落地规则提取（并入规则库）

### 4.1 估值规则：市赚率（ericwarn丁宁，本次最高价值单条）

```
PR = PE ÷ ROE ÷ 100
巴菲特校准：可口可乐 1988 建仓 0.474PR、1989 加仓 0.326PR，均值 0.4PR
买入带：PR ≤ 0.4（4折）最优；0.4-0.6（5-6折）可买；> 0.8 回避
适用：ROE 稳定的价值股（用 TTM PE + TTM ROE）
```

**与已有体系的关系**：与 daily_stock_analysis 理念6（PE 偏高需说明）相比，市赚率把 PE 和 ROE 耦合成单一比率，**可直接作为选股过滤器**（PR≤0.6 且 ROE≥15%）。

### 4.2 市场环境规则：牛熊指标（未曾真知）

- 指数均值回归型牛熊指标（与院聘教授合编）——与 dsa 情绪周期（换手率分档）、tsp 六阶段情绪周期**三方互证**：牛市/熊市判断需要"指数位置+均值回归"双确认

### 4.3 事件驱动修正：预期差原则（闷得而蜜）

```
事件(利好/利空) → 先判断"市场事先预期到什么程度" → 只交易差值
- 利好+超预期 → 涨；利好+已预期（股价已涨）→ 不涨反跌（兑现）
- 利空+超预期 → 跌；利空+已预期 → 低开高走
```

**落地**：本项目的事件驱动规则（dsa event_driven 策略）必须叠加"预期差"过滤——**公告日涨幅已反映的利好不追**。

### 4.4 生存规则：现金流哲学（赛博格Cyborg）

- "没有一家机构因为收益高而活下去，都因为**有稳定现金流**"；个人投资者"手里的钱越少越着急，越着急越犯错"——**Kelly 公式的资金哲学基础**（永远不满仓、保留容错）
- 放弃日内交易、做低杠杆周期行情——与 docs/09 的"倒T小赚+动量追涨"形成"仓位哲学 vs 战术"的互补

### 4.5 负面清单：赌题材四连亏（刘浪）

| 年份 | 题材 | 仓位 | 结果 |
|------|------|------|------|
| 2013 | 页岩气（仁智股份） | 全仓 | -27% |
| 2018 | 充电桩（科士达） | 半仓 | -17% |
| 2020 | 全球米价（北大荒） | 全仓 | -13% |
| 2022 | 自动驾驶（德赛西威） | 全仓 | -2x% |

**与 docs/07 互证**：多空博弈社"深跌低吸"8条-5.03%、刘浪"赌题材"四次全亏——**散户两大死法：接飞刀 + 追题材脉冲**。规则库的 R07/R08 闸门（情绪顶/游资反向）正是对冲这两类行为。
