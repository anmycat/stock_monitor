## 一、核心结论（TL;DR）

1. **工程迭代零破坏得证（本阶段第一目标）**：D31/D32 全部改动（M2' 腾讯三层代码池、B5 数据卫生、B4 API 默认值、审计修复）均在生产代码侧，研究线为离线静态数据 + rules JSON，两跑非 R06 信号 **225 笔逐字段零差异**；生产链路交叉校验 **27/27 池完整、27/27 价格一致、B5 全市场零误剔**。

4. **数据延伸至 10-21 并发现两处单位事实（调整项②）**：TDX 主源 + 腾讯不复权独立校验双源一致；**逐票锚点标定发现腾讯对 688498（科创板高价股）返回 vol=股而非手**（amount/vol 反推均价 1021 元佐证）；**旧 `index_daily.json` 的 vol 单位实为股**（extend 脚本旧注记"手"有误，本次勘误，不影响计算——指数仅收盘价参与 regime）。
5. **第三窗口定稿口径三窗口稳定（本阶段核心验证）**：定稿口径 6M 538 笔 +0.29% → 3M-v1 **201 笔 / 44.3% / +0.88%** → 3M-v2 **196 笔 / 44.4% / +0.74%** → 3M-v3 **195 笔 / 44.1% / +0.68% / +131.72%**；月度形态复现（8 月强、9 月弱、10 月承压）；R02 第三窗口 19 笔 −0.12%/−2.32% 与 docs/22 归因分析的"重叠 19 笔"**分毫不差**——窗口滚动效应归因获第三方窗口确认。
6. **Kelly 三窗口对照提出 v1.7 建议（调整项③，待用户确认，rules JSON 不动）**：R04 半凯利 2.92%→2.84%→**2.36%**、混合 3.70%→1.92%→**1.69%** 持续下衰减，按"取保守者"原则建议下修执行值；R01/R02/R05 三窗口观测支持维持 v1.6 值。按项目约定（重大 rules 变动需用户显式确认），本次仅登记中间态，**未改 rules JSON**。

## 二、回归复跑与差异归因（第一目标：证明工程改动零破坏）

### 2.1 复跑方法与判据

用**同一份静态数据**（10-21 延伸前）重跑 `validate_3m_recent_v2.py`，与 2026-10-21 07:20 的已提交产出（docs/22 数字来源）逐字段比对。若工程改动破坏了研究线，信号集或统计应出现随机漂移；实际观测到唯一的系统性差异全部集中在 R06。

### 2.2 归因链（三个证据）

| 证据 | 内容 | 结论 |
|---|---|---|
| 信号集比对 | 非 R06 信号 225 笔：键集合零差异、逐字段零差异（committed vs 复跑） | 工程改动对信号生成零影响 |
| 规则 diff | v1.6（commit `b576c73c`，10-21 23:14，晚于 07:20 跑批）仅改 R06 `direction: short_then_long→avoidance` 与 R12 `default_enabled`（后者引擎不消费，无功能影响） | 差异源自 rules 落库，非数据/代码回归 |
| 引擎机制 | `run_rule` 的 `t_pair = direction=="short_then_long"` 分支随 direction 改变而关闭，R06 落入常规买入分支（T+1 开盘买、持 5 日） | 口径切换的机制解释 |

## 三、数据延伸至 2026-10-21（双源拉取 + 三重校验）

`scripts/fetch_tail_1021.py`：每源取 8 根日K（覆盖 10-14~10-21），校验通过后仅追加 10-21 一根 bar，不动已有历史。

| 事实 | 证据 | 处置 |
|---|---|---|
