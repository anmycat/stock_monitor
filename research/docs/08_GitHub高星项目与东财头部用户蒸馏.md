## 二、GitHub 高星项目蒸馏

### 2.1 ZhuLinsen/daily_stock_analysis（66,293★）——策略配置化范式

**主流程**：抓取数据 → 技术分析/新闻检索 → LLM 分析 → 生成报告 → 通知推送。覆盖 A股/港股/美股。

**七条核心理念（默认技能基线，全部可执行量化）**：

| # | 理念 | 口径 |
|---|------|------|
| 1 | 严进策略（不追高） | 乖离MA5>5% 坚决不买；<2% 最佳买点；2-5% 小仓 |
| 2 | 趋势交易 | 必须 MA5>MA10>MA20 多头排列，空头坚决不碰 |
| 3 | 效率优先（筹码） | 90%集中度<15% 筹码集中；70-90%获利盘警惕回吐；现价高于均价5-15%健康 |
| 4 | 买点偏好 | 最佳：缩量回踩MA5获支撑；次优：回踩MA10；跌破MA20观望 |
| 5 | 风险排查 | 减持/预亏/监管处罚/行业利空/大额解禁——一票否决 |
| 6 | 估值关注 | PE 明显偏高需在风险点说明 |
| 7 | 强势股放宽 | 龙头可放宽乖离，轻仓追踪但必须设止损 |

**15 个内置策略 YAML**（category: trend/pattern/reversal/framework）：
情绪周期、多头趋势、缠论、龙头、热点主题、事件驱动、成长质量、预期重估、均线金叉、放量突破、缩量回调、箱体震荡、底部放量、一阳三阴、波浪理论

**YAML 模板字段**：`name/display_name/category/core_rules(关联理念编号)/required_tools/aliases/default_active/default_router/default_priority/market_regimes/instructions`——**零代码，自然语言即策略**

**评分机制**：每个策略可给 `sentiment_score ±N` 调整（情绪周期底部+14~20、顶部-12~-20；龙头确认+10、板块轮动+5），多策略信号汇总成单一分数

**架构细节**：
- 策略=skill，`defaults.py` 是"默认基线"；**显式选择 skill 时不叠加默认基线**（防规则漂移）
- 多 agent 路由 fallback 子集 + `regime(市场状态) → skill` 映射
- `src/core` 主流程编排 / `src/services` 业务层 / `src/repositories` 数据层 / `src/reports` 报告 / `data_provider` 多源fallback
- 单一数据源失败不拖垮主流程；报告结构变化必须同步 CHANGELOG

**情绪周期策略（最完整的可复用量化模板）**：
- 换手率分档：<0.5% 冷淡底部 / 0.5-2% 正常 / 2-5% 活跃勿追高 / >5% 警惕顶 / >10% 极度过热
- 换手率走势：由高向低+缩量→退潮；由低向高+陡增→启动；单日暴量超前5倍→主力出货
- 情绪底部特征（3+/5 买入）：20日换手率近一年低位 / 量低于60日均量50%+ / 新闻低调负面 / 股价MA20附近无恐慌暴跌 / 机构持仓稳定
- 情绪顶部特征（3+/5 减仓）：5日换手率>20日均值2倍 / 量脉冲放大 / 利好兑现新闻 / 偏离MA5>8% / MACD顶背离

### 2.2 wbh604/UZI-Skill（7.2k★）——66位大佬评审团

**定位**：22维数据 + 66位投资者各自按方法论打分（Pydantic Signal）+ 机构级估值建模 + 杀猪盘检测。

**九大流派 66 人**：经典价值6 / 成长4 / 宏观对冲5 / 技术趋势4 / 中国价投6 / **A股游资22** / 量化3 / 科技领袖 / AI卡位猎手

**严格输出契约（Signal）**：`investor_id/name/group/signal(bullish|neutral|bearish)/confidence/score/verdict(8档)/reasoning/comment(本人语言风格)/pass[]/fail[]/ideal_price/period`

**Confidence 校准（工程关键）**：
- 85-100：核心方法论硬指标全部命中或全部不命中
- 60-84：多数命中
- 30-59：部分命中需等待信号
- 0-29：方法论不适用/信息不足

**游资射程预过滤（F组特殊机制，对本项目最重要）**：
- `is_in_range(nickname, ticker_features)` 先判断风格射程，不在射程 → `neutral/不适合/confidence=90`
- 射程示例：章盟主=市值>200亿+趋势向上+大成交；赵老哥=板块辨识度龙头+一二板潜力；北京炒家=市值20-80亿+题材+机构持仓<10%+首板；佛山无影脚=小盘+超跌
- **反向指标显式标记**：佛山无影脚买入→高confidence bearish；拉萨天团多席位同现→bearish
- 评分公式：K线(Stage/量能/突破)×30 + 龙虎榜匹配×30 + 情绪×20 + 事件×20；≥80强烈买入，60-79买入

**语言风格守则**：每位投资者的 comment 必须像本人（每组 reference 附真实公开语录 few-shot）——**人格化是传播力的核心，也是识别"假大佬"的检测点**

**Deep Analysis 铁律**："你不是脚本的搬运工——脚本负责算数，你负责推理和下结论"。脚本提供5类产物：原始数据(22维)/机构建模(22种方法)/65人评委量化裁决/数据完整性报告/可审计 methodology_log

### 2.3 oficcejo/aiagents-stock（约2k★）——六位AI分析师团队

**单股深度分析流程**：技术/基本面/资金/风险/情绪/新闻 6位分析师 → 团队讨论 → 最终决策 → PDF报告

**统一决策输出契约（社区标准五字段）**：`rating`（强烈买入~强烈卖出5档）/ `confidence_level` / `entry_range` / `take_profit` / `stop_loss`

**规则化选股矩阵**（每个都是可执行条件）：
| 策略 | 规则 |
|------|------|
| 主力选股 | 问财主力资金净流入TOP100 → 多维筛选 → AI精选3-5只 |
| 低价擒牛 | 股价<10元 + 净利润高增长 + 深圳A股 |
| 小市值 | 总市值≤50亿 + 营收增长≥10% + 净利增长≥100% |
| 净利增长 | 净利润增长率≥10%，成交额由小到大 |
| 低估值价值 | PE≤20 + PB≤1.5 + 股息≥1% + 负债≤30% |

**策略分析模块**：智策板块（4智能体：宏观策略师/板块诊断师/资金流向/市场情绪解码 → 多空+轮动+热度三维）/ 智瞰龙虎（龙虎榜×5分析师，18:00-21:00分析最佳；仓位参考：高确定性30-40%/中20-30%/低10-15%）/ 宏观周期（康波×美林时钟×中国政策）/ 新闻流量监测（20平台→AI情绪→置信度≥0.6告警）

**工程要点**：数据源降级链 TDX→Tushare→AKShare；"仅交易时段监控"使API消耗↓75%；统一分析规范（所有分析必须走同一入口，字段/解析/UI/通知全链统一）

### 2.4 shy3130/tick-stock-panel（5.8k★）——量化工作台

**架构主线"核心是引擎，其余皆插件"**：核心域8个（数据底座/能力路由/策略与回测/因子与挖掘/环境数据生产/监控推送管道等）+ 扩展域5通道（数据源插件/扩展数据表/自定义策略信号/页面扩展/后端custom）。19个页面中11个官方页面本身就是单文件扩展（删除目录即卸载）。

**关键机制**：
- **能力路由矩阵**：6类数据集按源声明能力独立路由，**换源不换口径**，指标与回测结果不变
- **单一 enriched 口径**：只存15列基础数据、现算68列指标信号；策略→回测→监控→复盘吃同一份数据
- **回测=实盘同路径**：策略执行只此一条 `StrategyEngine.run`；分钟策略逐日回放 + **"当日已知"纪律，杜绝未来函数**
- **市场环境模块**：情绪周期6阶段 + 概念/行业主线排名
- **连板梯队**：连板统计 + 概念轮动 + 盘后AI复盘
- **异动监控**：竞价/盘中/偏移三类 + 实时弹窗/语音播报/飞书推送
- **因子挖掘纪律**：样本外搜索多因子组合，"显式发布、永不上线"（防过拟合）
- **AI助手**：21查询+4动作工具，**写操作必须确认卡放行**；工具足迹逐条可核对是设计铁律
- 开放能力：Token六档scope + 65端点契约 + SSE事件流 + MCP 12工具；契约快照测试+CI守护

### 2.5 四项目共性模式（对项目的直接启示）

| 共性 | 具体表现 | 我们的落地 |
|------|---------|-----------|
| 策略即配置 | YAML 自然语言（dsa）/ DSL 因子（tsp） | 博主方法论蒸馏产物 = skill YAML，可版本化可分享 |

| 执行确认卡 | AI 写操作必须人工确认 | 涉及资金动作的铁律 |

| 可复用性 | 六项能力模型+财报SOP可直接规则化 | 交易动作-实盘对照方法论（docs/07） | 盘前主线判断（西南小游资）+情绪周期量化（dsa模板）+射程过滤（UZI） |

**关键交叉发现**：
1. **静水2008 的"趋势投资"定位与 daily_stock_analysis 理念2（MA5>MA10>MA20多头排列）完全同构**——两个独立来源收敛到同一规则，可信度高
2. **多空博弈社的"深跌低吸必亏"（docs/07：8条-5.03%）与 daily_stock_analysis 理念1"严进策略不追高"互补**：一个禁止追高、一个禁止接飞刀，合起来就是"只在动量确认后回踩介入"
3. **文辉永续的实盘换仓叙事**（"一半仓位换到阳光电源"）与多空博弈社的做T截图互为镜像：一个晒思考、一个晒动作
4. **割不动的韭菜9527 的"机构研报二传"模式**是项目抓取链路的现成数据源：高盛/花旗/长江电新观点 → 可验证的预测记录

## 四、对项目开发的落地建议

### 4.1 架构：采用"多博主智能体 + 评审团共识"模式

```
                ┌──────────────────────────────────────┐
                │  博主方法论库（skill YAML 化）          │
                │  静水2008 / 多空博弈社 / 东财头部×N    │
                └──────────────────────────────────────┘
                                │
                ┌───────────────┼───────────────┐
                ▼               ▼               ▼
        【analyst agent】  【analyst agent】  【analyst agent】
         每个博主带：        每个博主带：       每个博主带：
         · 数据白名单        · 射程定义         · 语言风格样本
         · 输出Signal契约    · confidence校准   · 历史准确率
                │               │               │
                └───────────────┼───────────────┘
                                ▼
                    【consensus 汇总 + 分歧检测】
                    输出：rating/confidence/
                    entry_range/take_profit/stop_loss
```

1. **每个博主一个 analyst agent**：输入该博主的 skill YAML（方法论）+ 数据白名单，输出标准 Signal 契约（借鉴 UZI-Skill + aiagents-stock 收敛的五字段）
2. **射程预过滤**：每个博主只对"能力圈内"的票输出观点（价投派不评题材股、游资派不评低PE白马）——否则 consensus 被噪声淹没
3. **confidence 按"硬指标命中数"校准**（85-100/60-84/30-59/0-29 四级）
4. **分歧检测**：多博主 Signal 打架时输出"分歧度"而非强行共识——分歧本身是信号（顶部往往一致看多）
5. **历史准确率回测**：每个博主维护"观点→次日/5日/20日盈亏"档案（方法同 docs/07 对多空博弈社做的事），作为该 agent 的权重

### 4.2 方法论资产库：三类可立即入库的规则

**A. 通用基线（daily_stock_analysis 七理念 + 我们的实盘验证）**：
- MA5>MA10>MA20 才允许买入（理念2）← 静水2008趋势投资同构
- 乖离MA5>5% 不买（理念1）← 与 docs/07"连涨追涨才有效"结合成：**动量确认（连涨≥2日）+ 乖离<5% 才追**
- 缩量回踩MA5/MA10 是首选买点（理念4）← docs/07"倒T先卖后买7/7全胜"的日内版
- 5日跌10%+才允许低吸（我们补的规则）← docs/07"深跌低吸8条仅12%胜率"的修正

**B. 市场环境判断（dsa 情绪周期 + tsp 六阶段 + 东财头部实践）**：
- 换手率分档（<0.5%底 / >5%警惕 / >10%过热）
- 顶部特征清单（5日换手率>20日均值2倍 / 偏离MA5>8% / MACD顶背离）
- 东财头部行为做交叉验证：盘前计划集中看多某主线时（西南小游资式），检查该主线是否已在顶部特征区

**C. 博主特色规则（逐个蒸馏入库）**：
- 滇南王：再造成本估值（水电站10-15年回本模型）、分红率视角
- 语润梧桐：布林上轨+年线+套牢盘消化三段式
- 花丛冷眼：板块轮动健康度（高位科技→低位消费切换才健康）
- 静神00988：筹码峰8形态（低位单峰密集+放量突破跟进；高位单峰密集=派发信号）
- 文辉永续：牛市换仓纪律（"好票太多"时的半仓轮动）

### 4.3 数据与风控

1. **数据源 fallback**：东财已开始屏蔽（aiagents-stock 2026.6 修复记录：K线切腾讯、行情切新浪），我们的抓取链需按 TickFlow/fuyao/TdxQuant/AKShare 多层设计
2. **杀猪盘检测**：UZI-Skill 的 trap-detector + 龙虎榜拉萨天团/佛山无影脚反向指标——东财头部中的"单票信仰派"（静神东方财富1043次）需区分"真信仰"与"出货喊单"
3. **防未来函数**：所有回测按"当日已知"纪律；博主观点打上发布时间戳，只用发布时点之前的数据评估
4. **情绪温度计**：只爱男大学生/新马门溪财经类高情绪账号的看多比例可做反向指标输入（多空博弈社已被验证为反向数据）
