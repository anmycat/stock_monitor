### 2.1 同花顺网页端 d.10jqka.com.cn —— 新增 Tier1（免登录、实测全通）

**接口地址**（全部 `[实测]` 可用，明文 HTTP，需伪装 UA+Referer+Cookie）`[文档]`

**返回字段** `[实测]`
- K线 12 字段：`date, open, high, low, close, volume(股), amount(元), turnoverRate(%), 空, ?, ?` —— **volume 单位是股**，与项目腾讯"688/689 返回股、其余返回手"的坑**不同源不冲突**，可直接落库
- 快照 items：`5`=代码 `6`=昨收 `7`=今开 `8`=最高 `9`=最低 `10`=最新 `13`=成交量(股) `19`=成交额(元) `69/70`=涨停/跌停 `74/75`=60日涨跌；顶层另有 `name/time/stockStatus/marketType/profit`

**限速/封号** `[社区]`：无公开官方频控；文档标注"偶发 502"；建议**同域串行 + 0.3~1s 间隔 + 失败快速降级**，不并发打

### 2.2 baostock —— 日 K 权威校验源（Tier1）

- **免注册/免 Key**：`bs.login()` 匿名即成功 `[实测]`；`pip install baostock` 本机实测装到 **0.9.4**（协议版本 `00.9.40`）
- **服务器（重要变更）** `[实测]`：`public-api.baostock.com:10030` ✅；`www.baostock.com:10030` ❌ 超时。自定义 TCP+zlib+CRC32 协议，登录 body `login\x1anonymous\x1123456\x10`；可用 `BAOSTOCK_SERVER_IP/PORT` 环境变量或 `cons.BAOSTOCK_SERVER_IP` 改写
- **核心接口** `[文档]`：`query_history_k_data_plus(code, fields, start_date, end_date, frequency, adjustflag)`（`d/w/m/5/15/30/60`；adjustflag 1=后复权 2=前复权 3=**不复权(默认)**）｜`query_all_stock(day)` 全股票列表（带 code_name）｜`query_trade_dates`｜`query_stock_basic`｜`query_stock_industry`｜`query_adjust_factor` 复权因子
  - 0.9.x 新增：`query_terminated_stocks` 退市、`query_suspended_stocks` 停牌、`query_st_stocks`、`query_stock_concept`、`query_daily_history_k_AStock(date)`（**一天全市场日线**）、`query_daily_adjust_factor(date)` —— **多数未在 `__init__.py` 导出，需 `from baostock.security.sectorinfo import ...`**
- **字段对齐（最佳）** `[实测]`：`date, code(sh.600519), open, high, low, close, volume(股), amount(元), pctChg(%), turn(换手%), tradestatus(1正常/0停牌), isST` —— **完全覆盖项目所需 11 字段且单位明确**
- **复权口径** `[社区]`：涨跌幅复权法，与通达信/同花顺口径不同 → **只当校验基准**，勿与腾讯 qfq 混用
- **限速/封号**：单连接单会话，`login()`/`logout()` 必须成对 `[实测]`；`[社区]` 官方无公开频控文档但服务端有熔断——单 IP 并发 ≤1、相邻请求 **≥800ms**（<750ms 概率性 RST）、单日约 3000 次后 429/socket 关闭次日重置、**高频会静默封 IP 1~24h**；另有实现称官方额度 **50000 次/日按公网 IP 计**
  - **本项目建议**：日频离线任务用，**串行 + 1s 间隔 + 单日预算封顶**，绝不进盘中主循环
- **实现难度**：适配层（登录态 + 分页迭代 `rs.next()`/`get_row_data()`）约 40~60 行

### 2.5 mootdx（pytdx 社区封装）—— Tier2

- **与 pytdx 的差异** `[文档]`：mootdx 是 pytdx 的**二次封装**（依赖 `pytdx>=1.67`），提供 `Quotes`（在线 TDX 二进制协议）/ `Reader`（**解析本地通达信 .day/lc1/lc5 文件，零网络零风控**）/ `Affair`（财务）/ `server`（智能选服）；pytdx 原项目 **2019-08 归档、无 LICENSE**，mootdx 是活着的继承者（MIT）
- **连接池/多服务器** `[实测]`：内置 `mootdx/consts.py` 的 `HQ_HOSTS` 共 **38 个双线节点:7709**，另有 `EX_HOSTS`(7720)、`GP_HOSTS`(财务)；`Quotes.factory(market='std', bestip=True)` **并发探测延迟最低节点**；`servers=[(ip,7709),...]` 可手动指定+故障切换
- **本机实测存活 14/38** `[实测]`：深圳双线主站1 `110.41.147.114`、上海双线主站6 `124.70.199.56`、上海双线主站9/10/11/12/13/14 `121.36.225.169 / 123.60.70.228 / 123.60.73.44 / 124.70.133.119 / 124.71.187.72 / 124.71.187.122`、武汉电信主站1 `119.97.185.59`、广州双线主站4/5/6/7 `124.71.9.153 / 116.205.163.254 / 116.205.171.132 / 116.205.183.150`
  - ➡️ **项目已知的 `117.34.114.x` 并不在 mootdx 内置列表里** → 用 mootdx 的 bestip 探测在 ECS 上找可达节点，**是解决"TDX 从 ECS 不可达"的最短路径**（比继续找 IP 列表更可行）
- **封 IP 风险**：**无 HTTP 风控、非爬虫**，TDX 私有 TCP 协议 → 风险最低；但服务器列表**逆向得来、2 年未更新** `[社区]`（mootdx 最后发版 2024-05，约 26 个月停滞）
- **无未来函数优势** `[社区]`：`client.bars()` 给**不复权价** + `client.xdxr()` 给**原始除权除息记录** → 自算 hfq 因子，规避所有厂商 qfq 归一化差异（项目已在踩腾讯 qfq 的坑）
- **字段**：`bars`→open/close/high/low/vol/amount/date；`quotes`→46 字段含五档；`transaction`→分笔（**offset=800 分页**）
- **实现难度**：适配层（连接池+重连+熔断）约 80~120 行

### 2.6 TdxAiData —— "是什么"已确认，但**不是免费**

- **是什么** `[文档]`：**通达信官方**的 TdxAiData Python 数据接口（Windows `.dll` / macOS `.dylib` / Linux `.so`，跨平台），封装 `tqs` 类，后台数据模式**不依赖通达信客户端**
- **安装** `[文档]`：`pip install tdxaidata`（本机查 PyPI：**最新 1.3.1**，`requires_python>=3.7`，仅可选依赖 pandas）
- **鉴权** `[文档]`：编辑 `site-packages/tdxaidata/lib/TdxAiData.ini`
  ```ini
  [TcHqHost]  ; 行情  HostName01=aihs.tdx.com.cn  Port01=7709
  [TcDsHost]  ; 数据  HostName01=aids.tdx.com.cn  Port01=7727
  [Token]      token=TDX-xxxxxxxx
  ```
  token 从**通达信个人版商城 → 会员中心 → 积分和 Key 管理 → 创建数据服务 Key（数据服务类型）** 获取；也可用环境变量 `TDX AI DATA LIB` 指向外部动态库目录
- **免费额度（关键）** `[社区]`：**注册即送 10000 积分**，单次调用**固定消耗 1 积分**（复杂查询约 15 积分）→ 约 1 万次简单查询；智能体广场每日签到 +100。**这是计费不是免费**，高频轮询会耗尽
- **接口（40 个通用 + 11 个 tqserver 特有）** `[文档]`：`get_market_snapshot` / `_batch` / `get_market_data` / `get_minute_data` / `get_tick_data` / `get_exday_data` / `get_divid_factors` / `get_zdt_data`（涨跌停）/ `get_stock_list` / `get_sector_list` / `get_stock_list_in_sector` / `get_trading_dates` / `get_financial_data` / `get_gpjy_value` / `get_bkjy_value` / `get_call_auction` / `subscribe` 实时订阅 等
- **字段**：`get_market_snapshot(code, ["Name","Price","Close"])`→dict；`get_market_data(field_list=["Open","High","Low","Close"], stock_list=["600000.SH"], period="1d", count=100, dividend_type="front")`→DataFrame
- **本机实测** `[实测]`：`aihs.tdx.com.cn`/`aids.tdx.com.cn` **DNS 可解析**（111.230.66.190 / 123.207.4.241），但 **7709/7727 端口本机不通**；`https://mcp.tdx.com.cn:3001/mcp` 返回 400（缺 key 的正常响应，服务在）
- **实现难度**：适配层 80~120 行（含 ini 解析 + 动态库加载）

### 2.7 iwencai 问财（自然语言选股）—— Tier3

## 四、给本项目的通用工程约束（基于本次实测）

1. **单位归一化集中在一处**：实测 同花顺=**股**、腾讯 qt 688/689=**股**/其他板=**手**、东财=**手**、baostock=**股**、新浪=**股**、扶摇=**股**。建议落库统一为**股**，转换只在适配层做一次。
2. **失败要"响"不要"哑"**：adata 吞异常成空 DataFrame 不适合生产；fuyao 的 `code`/HTTP 200 契约是最佳范式 —— **每个源统一映射成 `(ok, data, err)` 信封**。
3. **换 host 不换源**是最低成本救回手段：实测东财 `push2` 全挂而 `push2ex` 全通；baostock 旧域名超时而新域名通；腾讯 `web.ifzq`/`ifzq` 双入口通而 `qp.ifzq` 502 → **每个源维护 2~3 个 host/入口做轮换**。
4. **TDX 类源用 bestip 探测替代硬编码 IP**：实测 38 个内置节点本机存活 14 个，存活集合与"知名 IP"无关联；`bestip=True` 并发探测延迟最低节点是最优解。
5. **本报告实测均来自本机（家庭宽带）**，生产 ECS 出口 IP 与网络路径不同 → **上线前必须在 ECS 上重跑连通性矩阵**（尤其 baostock 的 `public-api` 域名、TDX 节点、fuyao 的 IPv6 解析、push2ex）。
6. 腾讯 `ifzq` 日K 的 qfq 复权建议改用**新浪 qfq.js 原始因子**或 **mootdx xdxr** 自算，规避"前复权历史价随除权重算 + 数据落在 `qfqday` 键下"两个坑。
